### 접근 방식 : 1. 인덱싱
```
def solution(array, commands):
    answer = []
    lst = []
    for i in range(len(commands)):
        lst = array[commands[i][0]-1:commands[i][1]]
        lst = sorted(lst)
        answer.append(lst[commands[i][2]-1])
    return answer
```
거의 다와서 헷갈렸던 것은

첫째, 우선 리스트는 range를 사용하는게 아니라 인덱싱을 사용해야한다는 것을 헷갈렸기 때문이다.

둘째, 리스트는 0번째부터 시작하므로 인덱싱할 때 -1을 해주어야 한다는 것을 까먹었기 때문이다.
