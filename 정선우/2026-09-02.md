### 접근 방식 : 동적 계획법(DP)
- 왜 이 방식으로 풀었나?
  - DP 문제를 처음 접해서 문제를 풀기 전에 동적 계획법의 개념부터 학습했다.
  - 모든 경로를 직접 탐색하는 대신, **각 위치까지 도달했을 때의 최대 누적합을 저장하고 다음 계산에 재사용**하는 방식으로 접근했다.
  - `dp[i][j]`를 `triangle[i][j]까지 도달했을 때의 최대 누적합`으로 정의했다.
  - 가운데 값은 이전 행에서 올 수 있는 두 경로 중 큰 값을 선택한다.

```python
dp[i][j] = max(dp[i-1][j-1], dp[i-1][j]) + triangle[i][j]
```

  - 단, 맨 왼쪽과 맨 오른쪽은 올 수 있는 경로가 하나뿐이므로 별도로 처리한다.
  - 마지막 행까지 계산한 후 `max(dp[-1])`을 통해 최댓값을 구한다.

- 시간복잡도, 공간복잡도 관점에서의 성능 비교
  - 삼각형의 모든 원소를 한 번씩 확인하므로 시간복잡도 : `O(N²)`
  - 별도의 DP 배열을 사용하므로 공간복잡도 : `O(N²)`

### 회고
- 몇 번만에 성공했는지 : DP 개념 및 구현 방법을 학습하며 해결
- 잘한 점 :
  - DP를 처음 접했지만 `이전 위치의 최적값을 이용해 현재 위치의 최적값을 구한다`는 기본적인 원리를 이해했다.
  - 문제를 보고 최적의 경로를 찾는 문제라는 점과 각 위치에서 이전 값들을 비교해야 한다는 구조까지는 스스로 생각할 수 있었다.
- 개선할 점 :
  - 이번 문제는 DP를 처음 학습하면서 풀었기 때문에 직접 작성한 코드가 많지 않았다.
  - `dp[i][j]`처럼 **DP에 무엇을 저장할 것인지 정의하고 점화식으로 만드는 과정**에 아직 익숙하지 않다.
  - 비슷한 DP 문제를 하나 더 풀면서 직접 DP 정의와 점화식을 만들어봤다.
