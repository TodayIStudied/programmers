### 접근 방식 : DFS + 백트래킹
- `visited`로 항공권 사용 여부를 관리하고, `path`에 이동 경로를 기록한다.
- 모든 항공권을 사용하지 못한 채 막히면 선택을 취소하고 다른 경로를 탐색한다.

### 복잡도
- 시간복잡도 : 최악의 경우 `O(N × N!)` — 가능한 항공권 순서를 탐색하고 각 단계에서 항공권을 순회한다.
- 공간복잡도 : `O(N)` — 방문 기록, 경로, 재귀 호출 스택

### 회고
- 몇 번만에 성공했는지 : GPT와 함께 DFS, 백트래킹 학습

- 잘한 점 :
  - DFS의 구조가 익숙하지 않아 전체 코드의 틀을 먼저 확인하고, 각 부분을 이해하는 방식으로 학습했다.

- 개선할 점 :
  - 아직 재귀함수와 백트래킹을 혼자 구현하기 어려우므로, 다음에는 종료 조건과 재귀 호출부터 직접 작성해 볼 필요가 있다.

- 새로 배운 점 :
  - **DFS(깊이 우선 탐색)** : 한 경로를 끝까지 탐색한 뒤 다른 경로를 확인하는 방식이다.
  - **백트래킹** : 현재 선택으로 정답을 완성할 수 없다면 이전 상태로 되돌아가 다른 선택을 시도한다.
  - `path.pop()`과 `visited[i] = False`로 경로와 항공권 사용 상태를 복구한다.
  - 같은 공항은 여러 번 방문할 수 있지만 같은 항공권은 한 번만 사용할 수 있으므로 `visited`는 항공권 인덱스 기준으로 관리한다.

- 느낀 점 :
  - DFS와 백트래킹을 처음부터 혼자 구현하기는 어려웠지만, **선택 → 재귀 탐색 → 실패 시 복구**라는 흐름을 이해하는 것이 중요하다는 걸 알게 되었다.
  - 다음에는 같은 유형의 문제를 직접 풀면서 재귀 호출과 상태 복구를 연습해야겠다.
