### 접근 방식 : Tree dp + DFS

- 부모-자식 관계를 트리 구조(`vector<int> myTeam[]`)로 구성
- DP 상태를 두 가지로 정의: `dp[cur][0]` (현재 노드 불참), `dp[cur][1]` (현재 노드 참석)
- DFS를 통해 자식 노드 끝까지 내려간 후, 상향식(Bottom-up)으로 최소 매출액 누적
- 현재 노드가 불참할 때 자식 중 최소 한 명은 참석해야 하므로, 자식이 모두 불참하는 최적해를 가질 경우 비용 증가가 가장 적은 자식(`min_diff`)을 강제로 참석시키는 조건 처리

### 회고

- 시도 횟수 : 3번
- 잘한 점 : 복잡한 조건 속에서도 문제의 핵심이 트리 DP임을 파악하고, 참석 여부에 따른 `dp[N][2]` 상태를 올바르게 정의하여 접근함
- 개선할 점 :
  - 트리 DP에서 자식 노드의 계산이 완전히 보장되어야 하므로, 큐(Queue)를 이용한 탐색보다 DFS 재귀를 활용하는 것이 훨씬 직관적이고 안전함을 숙지
  - 상태 전이 시 현재 노드에 `dp[c][1]`이 아닌 `dp[c][0]`을 더해야 하는 경우 등, 부모와 자식 간의 비용 선택 로직을 구현할 때 변수 혼동 주의
