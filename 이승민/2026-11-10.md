### 접근 방식 : 1. 해시/집합 (Counter)
- 왜 이 방식으로 풀었나?
  - 최대로 가져갈 수 있는 폰켓몬 종류 수를 구하는 문제라 중복 제거한 종류의 수가 핵심
  - 가져갈 수 있는 최대 마릿수는 N // 2
  - `Counter`로 폰켓몬 종류의 수(`len(Counter(nums))`)를 구한 뒤 N // 2와 비교
  - 고유 종류 수가 N // 2보다 많으면 최대 N // 2개만 고를 수 있고, 적으면 종류 수만큼만 선택 가능
- 시간복잡도, 공간복잡도 관점에서의 성능 비교 
  - 시간복잡도: O(N) (배열 길이 N <= 10,000, Counter 생성에 O(N) 순회)
  - 공간복잡도: O(N) (해시맵에 고유 종류 저장)
  - 정확성 테스트 통과 (1ms 미만)

### 회고 
- 몇 번만에 성공했는지 : 1번
- 잘한 점 : 선택 가능한 최대 마릿수(N // 2)와 고유 종류 수의 상한 관계를 빠르게 파악한 점
- 개선할 점 : 빈도수 자체는 필요 없고 중복 제거만 하면 되므로 `len(set(nums))`를 쓰거나 `min(len(nums) // 2, len(set(nums)))` 한 줄로 더 단순하게 줄일 수 있음
