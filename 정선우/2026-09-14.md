### 접근 방식 : Dictionary + List
- 왜 이 방식으로 풀었나?
  - 이름과 추억 점수가 각각 같은 인덱스에 위치하므로 Dictionary의 `key:value` 형태로 저장했다.
  - 각 사진을 순회하면서 해당 인물이 Dictionary에 존재하면 점수를 더하고, 사진별 총점을 List에 저장했다.

### 회고
- 몇 번만에 성공했는지 : 1회

  - 문제를 읽고 바로 `Dictionary + List`를 이용하는 방법을 떠올려 한 번에 해결했다.
  - 이전에는 Python의 List 문법을 Java의 배열/List 문법과 자주 혼동했는데, 쉬운 Lv.1 문제를 반복해서 풀면서 Python 문법이 점점 익숙해지고 있다.
  - 최근 여러 문제를 풀면서 List, Queue, Stack, 2차원 배열을 문제 상황에 맞게 떠올리는 것이 이전보다 자연스러워졌다.
  - 문제를 보고 어떤 자료구조를 사용할지 판단하는 감각이 조금씩 생기고 있는 것 같다.
