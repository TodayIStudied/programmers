### 접근 방식 : Heap
- 처음에는 정렬한 뒤 가장 작은 값 2개를 꺼내서 섞는 방법을 생각했다.
- 하지만 새로운 값을 추가할 때마다 다시 정렬해야 하므로, 최솟값을 반복해서 꺼내고 새로운 값을 추가하는 데 적합한 Heap을 사용했다.

- 시간복잡도
  - `heapify()` : `O(N)`
  - 매번 전체를 다시 정렬하지 않고 Heap을 이용해 최솟값을 관리할 수 있다.

### 회고
- 몇 번만에 성공했는지 : 2회

- 개선할 점 :
  - Heap에 원소가 하나만 남았는데도 `K`보다 작은 경우를 처리하지 못해, 1회 시도 시 실패했다.

- 새로 배운 점 :
  - Heap은 전체를 완전히 정렬하는 것이 아니라 **최솟값을 빠르게 꺼낼 수 있도록 관리하는 자료구조**이다.

```python
heapq.heapify(arr)      # 리스트를 Heap으로 변환
heapq.heappop(arr)      # 최솟값 제거 및 반환
heapq.heappush(arr, x)  # 새로운 값 추가
```

  - `heappop()`으로 최솟값을 제거하면 Heap이 다시 정리되고, 다음 최솟값이 다시 `[0]`에 위치한다.
  - 따라서 최소 Heap에서는 `arr[0]`만 확인해도 현재 최솟값을 알 수 있다.

- 느낀 점 :
  - 처음 생각한 **정렬 → 가장 작은 두 값 제거**라는 방향 자체는 맞았지만, 이를 계속 반복해야 할 때는 Heap이 시간복잡도와 효율 측면에서 훨씬 적합하다.
