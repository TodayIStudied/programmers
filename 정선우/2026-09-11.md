### 접근 방식 : 순차 비교 + 인덱스 계산
- 왜 이 방식으로 풀었나?
  - 처음에는 `n`명의 참가자별로 리스트를 따로 만들어 단어를 분배하는 방식으로 접근했다.
  - `words.pop(0)`을 이용해 단어를 앞에서부터 꺼내 각 참가자에게 배정하려고 했다.
  - 이후 굳이 참가자별 리스트를 만들지 않고, `words` 자체를 앞에서부터 순회하면서 이전 단어의 마지막 문자와 다음 단어의 첫 문자를 비교하는 방식으로 접근을 바꿨다.

```python
for i in range(len(words) - 1):
    if words[i + 1][0] != words[i][-1]:
        # 탈락자 계산
```

- 탈락 위치를 기준으로 `n`으로 나눈 몫과 나머지를 이용해 몇 번째 사람인지, 몇 번째 차례인지 계산하려고 했다.

```python
member = (i + 2) % n
number = (i + 2) // n
```

### 현재 막힌 점
- 처음 생각한 `n`개의 리스트로 단어를 분배하는 방식이 필요한지 확신이 들지 않았다.
- `for i in n`처럼 숫자 자체를 반복문에서 사용할 수 없다는 점에서 구현이 막혔다.
- 끝말잇기 조건 중 이전 단어와 다음 단어의 연결 여부는 비교할 수 있었지만,
  - 이미 나온 단어인지 확인하는 부분
  - 탈락자의 번호와 차례를 정확히 계산하는 부분
에서 아직 감을 잡지 못했다.
- 몫과 나머지를 이용하면 참가자 번호와 차례를 구할 수 있을 것 같지만, `0`이 나오는 경우를 어떻게 처리해야 하는지 아직 정리가 필요하다.

### 회고
- 아직 문제를 완전히 해결하지는 못했다.
- 처음에는 참가자별로 데이터를 다시 나눠 저장하려고 했지만, 문제를 다시 보면서 `words`를 순서대로 비교하는 것만으로도 일부 조건은 처리할 수 있다는 것을 알게 되었다.
- 이번 문제는 단순히 문자열을 비교하는 것보다 **현재 인덱스가 몇 번째 사람의 몇 번째 차례인지 계산하는 부분**이 더 어렵게 느껴졌다.
- 불필요하게 자료구조를 새로 만들지 않고, 기존 입력의 순서와 인덱스를 활용하는 방법을 더 연습해야겠다.
