### 접근 방식 : 수학 (인덱스 규칙)

- n이 최대 10^7이라 n×n 배열을 실제로 만들면 메모리·시간 모두 초과 → 배열을 만들지 않고 값을 바로 구하는 방식으로 접근
- 1차원 인덱스 i를 2차원 좌표로 바꾸면 행 = i / n, 열 = i % n
- 채워지는 규칙을 보면 (행, 열) 위치의 값은 max(행, 열) + 1 → left~right 구간만 돌면서 바로 계산
- left, right가 n^2 범위까지 커질 수 있어 long long으로 처리

### 회고

- 몇 번만에 성공했는지 : 1번
- 잘한 점 : 문제에 적힌 과정을 그대로 구현하지 않고 규칙을 찾아 O(right - left)로 해결함. 결과 배열 크기만큼은 무조건 만들어야 하므로 시간 복잡도상 최적
- 개선할 점 : 결과 크기를 미리 알고 있으므로 answer.reserve()로 재할당을 줄일 수 있었음. 또 매 원소마다 /, % 연산을 하는 대신 시작 좌표만 한 번 구하고 열을 1씩 늘리다 n이 되면 다음 행으로 넘기면 상수 시간도 줄일 수 있음
