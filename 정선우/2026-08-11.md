# 올바른 괄호

## 문제 정보

* 플랫폼: Programmers
* 난이도: Level 2
* 문제 번호: 12909
* 사용 언어: Java
* 분류: Stack, 문자열

## 문제 요약

`(`와 `)`로 이루어진 문자열이 주어졌을 때 괄호가 올바르게 짝지어져 있는지 확인하는 문제이다.

예를 들어

```text
()()
```

와

```text
(())()
```

는 올바른 괄호이므로 `true`이다.

반면

```text
)()(
```

또는

```text
(()(
```

는 올바르게 짝지어져 있지 않으므로 `false`이다.

---

## 문제 접근

처음에는 첫 번째 문자와 다음 문자가 서로 다른지 비교하면 된다고 생각했다.

하지만

```text
)(
```

처럼 서로 다른 문자이더라도 `)`가 먼저 등장하면 올바른 괄호가 아니다.

따라서 단순히 앞뒤 문자를 비교하는 것이 아니라 **먼저 등장한 `(`를 기억하고 있다가 `)`가 등장했을 때 짝을 맞춰야 한다.**

이러한 구조는 가장 마지막에 넣은 값을 가장 먼저 꺼내는 `Stack`을 이용할 수 있다.

```text
'(' 등장
→ Stack에 저장

')' 등장
→ Stack에서 '(' 하나 제거
```

---

# Stack

Stack은 **LIFO(Last In, First Out)** 방식의 자료구조이다.

즉,

```text
가장 마지막에 들어온 값
        ↓
     가장 먼저 나감
```

의 구조를 가진다.

예를 들어

```text
push('(')

┌───┐
│ ( │
└───┘

push('(')

┌───┐
│ ( │ ← 가장 최근에 들어옴
├───┤
│ ( │
└───┘
```

여기서 `pop()`을 하면 가장 위에 있는 값이 먼저 제거된다.

```text
pop()

┌───┐
│ ( │
└───┘
```

---

## Stack 기본 사용법

### Stack 생성

```java
Stack<Character> stack = new Stack<>();
```

`Character`는 `char`의 Wrapper Class이다.

이번 문제에서는 `(` 문자를 저장하므로 `Character` 타입의 Stack을 사용했다.

### 값 넣기

```java
stack.push(c);
```

Stack의 가장 위에 값을 추가한다.

### 값 꺼내기

```java
stack.pop();
```

Stack의 가장 위에 있는 값을 꺼내면서 제거한다.

### Stack이 비어있는지 확인

```java
stack.isEmpty();
```

Stack이 비어있다면 `true`, 값이 존재한다면 `false`를 반환한다.

---

# Stack을 사용한 풀이

```java
import java.util.*;

class Solution {
    boolean solution(String s) {

        // '('를 저장할 Stack 생성
        Stack<Character> stack = new Stack<>();

        // String을 char[]로 변환한 후
        // 문자를 하나씩 c에 넣으며 순회
        for (char c : s.toCharArray()) {

            // '('가 등장하면 Stack에 저장
            if (c == '(') {
                stack.push(c);

            } else {

                // ')'가 등장했는데 Stack이 비어있다면
                // 짝을 맞출 '('가 존재하지 않음
                if (stack.isEmpty()) {
                    return false;
                }

                // 짝을 맞출 '(' 하나 제거
                stack.pop();
            }
        }

        // 모든 문자를 확인한 후
        // Stack이 비어있어야 모든 괄호가 짝을 찾은 것
        return stack.isEmpty();
    }
}
```

## 동작 과정

예를 들어

```text
(())
```

가 들어왔다고 생각한다.

처음에는 Stack이 비어있다.

```text
[]
```

첫 번째 `(`:

```text
push

[(]
```

두 번째 `(`:

```text
push

[(, (]
```

첫 번째 `)`:

```text
pop

[(]
```

두 번째 `)`:

```text
pop

[]
```

모든 문자를 처리한 후 Stack이 비어있으므로

```java
stack.isEmpty()
```

의 결과는 `true`이다.

## 왜 isEmpty()를 먼저 확인해야 하는가?

다음과 같은 입력을 생각할 수 있다.

```text
)(
```

첫 번째 문자부터 `)`가 등장한다.

하지만 Stack에는 아직 아무것도 들어있지 않다.

```text
[]
```

이 상태에서 바로

```java
stack.pop();
```

을 실행하면 꺼낼 값이 존재하지 않으므로 오류가 발생한다.

따라서 먼저

```java
if (stack.isEmpty()) {
    return false;
}
```

를 이용해 확인해야 한다.

즉,

```text
')' 발견

↓
Stack이 비어있는가?

YES → 짝지을 '('가 없음 → false

NO  → '('가 존재함 → pop()
```

순서로 처리한다.

# 새롭게 배운 내용

## 1. 문자열을 for-each로 순회하기

Java의 `String`은 다음처럼 바로 for-each를 사용할 수 없다.

```java
for (char c : s) { // 불가능
}
```

따라서 `toCharArray()`를 이용한다.

```java
s.toCharArray()
```

예를 들어

```text
String
"(())"

    ↓ toCharArray()

char[]
['(', '(', ')', ')']
```

로 변환된다.

따라서

```java
for (char c : s.toCharArray()) {
}
```

라고 작성하면 문자열의 문자를 하나씩 가져올 수 있다.

실행 과정은 다음과 같다.

```text
1회차 → c = '('
2회차 → c = '('
3회차 → c = ')'
4회차 → c = ')'
```

---

## 2. 일반 for문과 for-each

일반 for문으로 문자열을 순회할 수도 있다.

```java
for (int i = 0; i < s.length(); i++) {
    char c = s.charAt(i);
}
```

이 방법은 `i`를 사용할 수 있기 때문에 **현재 문자의 인덱스가 필요한 문제**에서 유용하다.

반면 이번 문제에서는 몇 번째 문자인지는 중요하지 않고 현재 문자가 `(`인지 `)`인지만 확인하면 된다.

따라서

```java
for (char c : s.toCharArray()) {
}
```

처럼 for-each를 사용하는 것이 간결하다.

```text
인덱스가 필요함
→ 일반 for + charAt(i)

값만 필요함
→ for-each + toCharArray()
```

# 더 효율적인 풀이

이번 문제는 괄호의 종류가

```text
(
)
```

두 종류뿐이다.

따라서 실제로는 Stack에 `(` 문자를 모두 저장하지 않고 **열린 괄호의 개수만 숫자로 기억할 수도 있다.**

```java
class Solution {
    boolean solution(String s) {

        int count = 0;

        for (char c : s.toCharArray()) {

            if (c == '(') {
                count++;
            } else {
                count--;

                // 닫는 괄호가 열린 괄호보다 먼저 많이 등장함
                if (count < 0) {
                    return false;
                }
            }
        }

        // 열린 괄호와 닫힌 괄호의 개수가 정확히 맞아야 함
        return count == 0;
    }
}
```

예를 들어

```text
(())
```

라면

```text
( → count = 1
( → count = 2
) → count = 1
) → count = 0
```

마지막에 `count == 0`이므로 `true`이다.

## Stack 풀이와 count 풀이 비교

### Stack

문자열을 한 번 순회하므로 시간 복잡도는

```text
O(N)
```

이다.

하지만 최악의 경우

```text
((((((((
```

처럼 모든 `(`를 Stack에 저장할 수 있으므로 추가 공간이 필요하다.

```text
공간 복잡도: O(N)
```

### count

문자열을 한 번 순회하므로

```text
시간 복잡도: O(N)
```

이다.

하지만 정수 변수 하나만 사용한다.

```text
공간 복잡도: O(1)
```

따라서 **이번 문제만 해결한다면 count 방식이 더 단순하고 공간 효율적이다.**

다만 Stack 풀이를 통해 Stack의 동작 방식을 익힐 수 있었다.

# 그렇다면 Stack은 언제 필요한가?

이번 문제는 괄호가 한 종류뿐이기 때문에 개수만 세어도 해결할 수 있다.

하지만 다음처럼 여러 종류의 괄호가 등장한다면

```text
()
{}
[]
```

단순히 개수만 세는 것으로는 부족하다.

예를 들어

```text
{ [ ( ) ] }
```

에서는 **가장 최근에 열린 괄호가 어떤 종류인지** 기억해야 한다.

이 경우 Stack을 사용하면

```text
{ → push
[ → push
( → push

) → 가장 최근 '('와 비교 후 pop
] → 가장 최근 '['와 비교 후 pop
} → 가장 최근 '{'와 비교 후 pop
```

처럼 처리할 수 있다.

즉 Stack은 **가장 최근에 들어온 데이터를 먼저 처리해야 하는 상황**에서 사용할 수 있다.

# 참고: Java에서 Stack을 사용할 때

이번 문제에서는 Stack 자료구조의 개념을 배우기 위해

```java
Stack<Character>
```

를 사용했다.

Java에서는 실제 코드를 작성할 때 Stack 용도로 `Deque`와 `ArrayDeque`를 사용하는 경우도 많다.

```java
Deque<Character> stack = new ArrayDeque<>();
```

하지만 현재는 구현체보다 Stack의 핵심 동작인

```text
push     → 넣기
pop      → 꺼내면서 제거
isEmpty  → 비어있는지 확인
```

을 이해하는 것을 우선한다.

# 배운 점

처음에는 괄호 두 개가 서로 다른지만 확인하면 된다고 생각했다.

하지만 `)(`와 같은 경우를 생각하면서 괄호 문제에서는 **문자의 종류뿐만 아니라 등장 순서도 중요하다**는 것을 알게 되었다.

이를 해결하기 위해 이전에 등장한 `(`를 Stack에 저장하고 `)`가 등장할 때 하나씩 제거하는 방법을 배웠다.

또한 Stack의 기본 동작인

```java
push()
pop()
isEmpty()
```

를 처음 사용해보았다.

문자열을 순회할 때도 항상 일반 for문을 사용하는 것이 아니라 인덱스가 필요하지 않다면

```java
for (char c : s.toCharArray())
```

와 같은 for-each 방식을 사용할 수 있다는 것을 배웠다.

마지막으로 자료구조를 배웠다고 해서 모든 문제에서 반드시 그 자료구조를 사용해야 하는 것은 아니며, 이번 문제처럼 단순히 상태의 개수만 기억하면 되는 경우에는 `count` 변수 하나로 공간 복잡도를 `O(N)`에서 `O(1)`로 줄일 수도 있다는 것을 알게 되었다.
