### 접근 방식 : 1. n진법 변환 + 수식 성립 여부 검증
- 문제를 보고 알고리즘보다는 구현에 치중된 문제라고 판단함
- 2~9 진법을 10진법으로 변환 및 그 역방향 변환을 통해 수식의 검증 여부를 검증
- 코드 재사용을 위해 수식 검정, X 추론을 calculate 함수에서 모두 처리함
- 구현 도중 문법 많이 까먹어서 고치면서 배움
  - 문자 찾기 - find / string::npos
  - sstream - 문자열 파싱
  - unordered_set - insert, *a.begin() (첫 element 가져오기)
  - toDex, toN 진법 구현
- 채점 중 에러 발생

### 접근 방식 : 2. 사전 후보 제거 
- 기존 방식은 15와 같은 숫자에서도 2, 3, 4, 5를 검증하나 숫자 '5'를 포함하면 6부터 점검해야함
- 잘못된 후보들이 검증되는 것을 막기위해 가장 앞단에 각 숫자를 확인하고 최댓값 이하 진수들을 후보에서 제외

### 회고 
- 몇 번만에 성공했는지 : 2번
- 잘한 점 : 구현에 집중하고 n진법 전환을 빠르게 구현하고 확인함. sstream은 처음 보는 방식이라 새롭게 배울 수 있었음.
- 개선할 점 : 코드 작성 과정에서 실수가 많았음. 사전 후보 제거를 제대로 적용하지 못하고 놓침.
