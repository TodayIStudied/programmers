### 접근 방식 : 1. 구현 (시뮬레이션 / while문)
- 왜 이 방식으로 풀었나?
  - 쿠폰 10장당 치킨 1마리를 받고, 서비스 치킨에도 쿠폰이 새로 발급되므로 `coupon >= 10`인 동안 반복문으로 시뮬레이션
  - 매 반복마다 `coupon // 10`만큼 서비스 치킨을 더해주고, 다음 쿠폰은 새로 받은 수(`coupon // 10`) + 나머지(`coupon % 10`)로 갱신
- 시간복잡도, 공간복잡도 관점에서의 성능 비교 
  - 시간복잡도: O(log N) (매 회차 쿠폰이 약 1/10로 줄어들어 `chicken <= 1,000,000`에서도 몇 번 안 돌고 끝남)
  - 공간복잡도: O(1) (변수 몇 개만 사용)
  - 정확성 테스트 통과

### 회고 
- 몇 번만에 성공했는지 : 2번
- 잘한 점 : 몫과 나머지 연산으로 쿠폰 교환이랑 잔여 쿠폰 관리를 간단하게 처리한 점
- 개선할 점 : 처음에 `coupon` 갱신할 때 이번 회차(`coupon // 10`)가 아니라 누적 `service_chicken`을 더해서 무한 루프 걸렸음. 누적 변수랑 현재 값 구분 주의하기
