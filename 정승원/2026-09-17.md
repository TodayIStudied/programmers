## 선분 3개 지우기

### 문제 설명

- 문제명: 선분 3개 지우기
- 풀이 URL: [선분 3개 지우기 — 내 풀이 코드](https://github.com/HappyPotatohappy/CodingTest/blob/bc69bea855e42cfdc0087c95f2f66717a9ba3412/trail2/선분%203개%20지우기/remove-three-segments.py)
- 사용 언어: Python
- 수직선 위에 놓인 N개의 선분 중 정확히 3개를 지웠을 때, 남은 선분들이 서로 겹치지 않게 되는 경우의 수를 구한다.
- 제거하는 순서가 달라도 같은 세 선분을 지웠다면 하나의 경우로 센다.
- 끝점이 맞닿는 경우도 겹치는 것으로 처리한다.

### 접근 방식 : 1. 제거할 세 선분의 조합 완전탐색 + 남은 선분 쌍 검사

- 왜 이 방식으로 풀었나?
  - 지울 선분 3개를 정하면 남는 선분들이 결정되므로, 제거할 조합을 모두 확인하는 방식으로 접근할 수 있다.
  - 남은 선분들이 서로 겹치지 않으려면 어떤 두 선분을 골라도 겹치지 않아야 한다.
  - 바깥쪽 삼중 반복문은 제거할 조합을 만들고, 안쪽 이중 반복문은 남아 있는 선분 쌍을 검사한다.
  - 한 쌍이라도 겹치면 해당 조합은 제외하고, 모든 쌍이 겹치지 않는 경우에만 `cnt`를 1 늘린다.

- 제거할 세 선분을 고르는 방법
  - `i`는 `range(n)`, `j`는 `range(i + 1, n)`, `k`는 `range(j + 1, n)`으로 순회한다.
  - 항상 `i < j < k`가 되므로 서로 다른 세 선분을 고르면서 같은 조합을 중복해서 세지 않는다.
  - 후보 개수는 N³개의 순서 있는 선택이 아니라 **C(N, 3)**개다.
  - `tmpl = l[:]`, `tmpr = r[:]`로 좌우 끝점 배열을 복사한 뒤, 제거할 선분의 왼쪽 끝점을 `-1`로 표시한다.
  - 이후 `tmpl[s] == -1` 또는 `tmpl[o] == -1`인 선분은 건너뛴다. 다음 조합에서는 다시 원본을 복사하므로 이전 제거 표시가 남지 않는다.

- 두 선분이 겹치는지 판정하는 방법
  - `check`는 선분 `[a1, b1]`, `[a2, b2]`를 받아 한 선분의 끝점이 다른 선분 안에 들어가는지 확인한다.
  - 네 조건 중 하나라도 만족하면 겹치므로 `0`, 모두 만족하지 않으면 겹치지 않으므로 `1`을 반환한다.
  - 양쪽 선분의 끝점을 모두 검사하기 때문에 한 선분이 다른 선분을 완전히 포함하는 경우도 잡아낸다.
  - 비교에 `<=`를 사용하므로 `[1, 3]`과 `[3, 5]`처럼 끝점만 같은 경우도 겹친다고 판단한다. `[1, 3]`과 `[4, 5]`는 겹치지 않는다. 이 예시는 설명용이다.

- 남은 선분 전체가 조건을 만족하는지 확인하는 방법
  - 각 제거 조합마다 `is_inter = 1`로 시작한다. 현재 코드에서 이 값은 ‘아직 겹치는 쌍을 발견하지 않았다’는 뜻이다.
  - 남은 선분의 인덱스 `s`, `o`를 `s < o`로 순회해 같은 쌍을 두 번 검사하지 않는다.
  - `check(...) == 0`인 쌍을 찾으면 `is_inter = 0`으로 바꾼다. 이후 다시 1로 바꾸지 않으므로 해당 조합은 집계되지 않는다.
  - 현재 `break`는 `o` 반복문만 종료한다. 다음 `s`에 대한 검사는 이어지지만, 이미 조합이 무효라는 표시는 유지되므로 결과에는 영향을 주지 않는다.

- 아이디어는 잘 생각 했는데 검사 함수를 잘 못 만들어서 2번 틀렸다.

- 시간복잡도, 공간복잡도 관점에서의 성능 비교
  - 시간복잡도: **O(N⁵)**
    - 제거할 조합은 C(N, 3)개로 O(N³)이다.
    - 각 조합에서 배열 복사에 O(N), 남은 선분의 모든 쌍을 검사하는 데 최악의 경우 O(N²)이 필요하다.
    - 한 쌍의 겹침 판정은 O(1)이므로 전체는 O(N³ × N²)이다.
    - 겹치는 쌍이 전혀 없으면 중간에 검사를 끝낼 수 없으므로 이 최악의 경우가 실제로 발생한다.
  - 공간복잡도: **O(N)**
    - 원본 끝점 배열 두 개와 현재 조합의 복사본 두 개를 저장한다.
    - 모든 제거 조합을 저장하지 않고 하나씩 검사하므로 보조 공간도 O(N)이다.
  - 시작점 기준으로 선분을 한 번 정렬한 뒤, 각 조합에서 제거된 선분을 건너뛰며 남은 이웃 선분만 검사하면 조합당 O(N), 전체 O(N⁴)으로 줄일 수 있다. 처음 정렬할 때 원래 인덱스를 함께 보관하면 제거 대상을 구분할 수 있다.

### 회고

- 몇 번만에 성공했는지: 3번.
- 잘한 점:
  - `i < j < k` 조건으로 제거 조합을 만들면서 중복 집계를 방지했다.
  - 남은 선분도 `s < o`인 쌍만 확인해 불필요한 중복 비교를 줄였다.
  - 양쪽 끝점과 등호를 포함해, 포함 관계와 끝점이 맞닿는 경우까지 검사했다.
- 개선할 점 (AI):
  - 겹침 조건은 `max(a1, a2) <= min(b1, b2)`로 간단하게 표현할 수 있다. 반대로 겹치지 않는 조건은 `b1 < a2 or b2 < a1`이다.
  - 남은 선분을 검사하는 함수를 따로 만들고 겹치는 쌍을 발견하면 바로 `False`를 반환하면, 현재처럼 바깥쪽 `s` 반복문이 계속 도는 일을 줄일 수 있다. 최악의 시간복잡도는 같지만 불필요한 검사가 줄어든다.
  - 삭제 표시용 `-1` 대신 인덱스가 `(i, j, k)`에 포함되는지 확인하면 실제 좌표 값에 의존하지 않고 제거 여부를 판단할 수 있다. 이 방식에서는 `l`, `r`을 수정하거나 복사할 필요도 없다.
  - 현재 의미에 맞춰 `is_inter`는 `is_valid`, `check`는 `is_disjoint`로 바꾸고 `True`/`False`를 반환하면 조건을 읽기 쉽다.
