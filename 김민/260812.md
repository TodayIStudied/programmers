### 접근 방식 : 1. 백트래킹
- answer로서 경우의 수를 모두 반환해야하기 떄문에 전부 탐색해야함
- 최대 n 값이 30이므로 O( C(n, 5) * m * 5 * 5) = 약 3,500만으로 완전탐색 백트래킹하기에 적절한 문제라고 판단하고 진행함
- 모든 경우의 수를 만든 후에 각 수가 valid 한 것인지 검정

- 몇 번만에 성공했는지 : 2번

- 개선할 점 : pruning 적용, vector 대신 array 사용 등을 통해 시간을 더욱 단축시킬 수 있음.
