### 접근 방식 : 1. 완전탐색
```
def solution(sizes):
    big = []
    small = []
    for i in range(len(sizes)):
        if sizes[i][0] > sizes[i][1]:
            big.append(sizes[i][0])
            small.append(sizes[i][1])
        else:
            big.append(sizes[i][1])
            small.append(sizes[i][0])
    return max(big) * max(small)
```

나의 경우, big과 small이라는 리스트를 만들어 추가한 후, max값을 비교하였다.
그런데 다른 사람의 풀이를 보니 굳이 이렇게 하지 않아도,
애초에 for문 내에서 2개를 불러올 수 있었음을 알게되었다.

```
for a, b in sizes:
    if a < b:
        a,b = b,a
```

두 개를 자리 바꾸는 방법도 아차차했다;
