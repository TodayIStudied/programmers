### 접근 방식 : 1. map 으로 2개의 iterator 순회하는 구현 
- 왜 이 방식으로 풀었나?
  - 단순 구현
  - map으로 2개의 iterator 순회하며 조건 만족하도록 list  만들고 다시 sum을 구하는 구현 
- 시간복잡도, 공간복잡도 관점에서의 성능 비교
  - 메모리: 11.6 MB, 시간: 0.09 ms

### 접근 방식 : 2. 1번 접근에서 메모리 개선 
- 왜 이 방식으로 풀었나?
  - map은 lazy하게 동작함
  - 따라서 map을 사용했는데 이를 list로 변환하는 건 map의 장점을 활용하지 못하는 코드임
  - 그렇기에 sum을 map이 lazy하게 반환하는 iterator에 곧바로 적용하도록 개선했음. 
- 시간복잡도, 공간복잡도 관점에서의 성능 비교
  - 메모리: 11.3 MB, 시간: 0.08 ms
  - 확실히 공간, 시간 측면에서 모두 개선됨
