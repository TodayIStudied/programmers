### 접근 방식 : 해시맵
- 문자열을 2글자씩 끊어 `isalpha()`로 영문자 쌍만 추출 후 `tolower()`로 소문자 통일
- 다중집합의 특성을 반영하기 위해 `unordered_map<string, int>`를 사용하여 각 글자 쌍의 빈도수(카운트)를 저장
- 교집합: 두 맵에 공통으로 존재하는 키의 `min(값1, 값2)` 누적
- 합집합: 두 맵에 존재하는 모든 키에 대해 `max(값1, 값2)` 누적
- 두 맵이 모두 비어있는 경우(합집합이 0) 예외 처리하여 분모가 0이 되는 에러 방지

### 회고
- 몇 번만에 성공했는지 : 2번
- 잘한 점 : 원소를 단순히 배열에 담지 않고 Map을 활용해 카운팅 방식으로 접근하여 교집합과 합집합 계산을 직관적이고 효율적으로 구현함
- 개선할 점 :
  - `tolower()`는 `int`(아스키코드)를 반환하므로 바로 문자열처럼 더하면 숫자 덧셈이 되어버림. 문자 변환 과정에서 자료형에 주의해야 함
  - `unordered_map` 순회 시 내부 키가 `const`로 취급되므로, 정확한 타입 명시보다는 `auto`를 활용하는 것이 에러 방지와 가독성에 좋음
  - 분모가 0이 될 때 발생하는 `floating point exception` 에러를 겪음. 수식 계산 전 0으로 나누는 엣지 케이스(공집합) 처리를 항상 우선적으로 고려해야 함
