### 문제 설명
- 풀이 URL : [소수 찾기](https://github.com/sunoo2468/codingTestPre/blob/main/Python/%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%98%EB%A8%B8%EC%8A%A4/2/42839.%E2%80%85%EC%86%8C%EC%88%98%E2%80%85%EC%B0%BE%EA%B8%B0/%EC%86%8C%EC%88%98%E2%80%85%EC%B0%BE%EA%B8%B0.py)
- 난이도 : Lv.2
- 알고리즘 : DFS / 백트래킹 / 소수 판별

### 접근 방식 : DFS + 백트래킹
- DFS를 이용해 주어진 숫자들을 조합하여 만들 수 있는 모든 숫자를 탐색한다.
- 생성한 숫자는 별도의 `is_prime()` 함수로 소수 여부를 판별한다.
- 소수는 `set`에 저장하여 중복을 제거하고, 최종 개수를 반환한다.

### 회고
- 몇 번만에 성공했는지 : 3회
- 잘한 점 :
  - DFS와 백트래킹의 기본 흐름을 이해하고 있어, `visited`를 이용한 선택과 복구 과정은 비교적 쉽게 떠올릴 수 있었다.
  - 하나의 함수에 모든 로직을 작성하기보다, 실제 기능을 개발하듯 숫자 생성과 소수 판별을 각각의 함수로 분리하는 구조를 학습했다.

- 개선할 점 :
  - DFS보다 소수 판별 로직을 구현하는 과정이 더 어려웠다.
  - 소수의 정의는 알고 있었지만, 이를 반복문과 조건문으로 구현하는 방법은 바로 떠올리지 못했다.
  - 앞으로는 알고리즘뿐 아니라 자주 사용하는 수학적 판별 로직도 직접 구현하는 연습이 필요하다.

- 새로 배운 점 :
  - 소수는 2부터 해당 숫자의 제곱근까지만 나누어 확인하면 판별할 수 있다.

- 느낀 점 :
  - 처음에는 DFS와 백트래킹 자체가 가장 어려울 것이라고 생각했지만, 이번 문제에서는 오히려 소수 판별이라는 개별 기능을 구현하는 것이 더 어려웠다.
  - 문제를 해결하려면 탐색 알고리즘을 아는 것뿐 아니라, 필요한 기능을 작은 함수로 나누고 각각 구현할 수 있어야 한다는 점을 느꼈다.
