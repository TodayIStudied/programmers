# 프로그래머스 Lv.2 — 배달

### 문제 설명
- 풀이 URL : [배달](https://school.programmers.co.kr/learn/courses/30/lessons/12978)
- 난이도 : Lv.2
- 알고리즘 : 다익스트라, 큐
- 학습 목표 : 가중치가 있는 그래프에서 최단 경로 구하기

### 접근 방식 : 다익스트라

1. 도로 정보를 양방향 그래프로 저장한다.
2. `distance` 배열을 무한대로 초기화하고, 출발점인 1번 마을의 거리를 0으로 설정한다.
3. 우선순위 큐에 `(이동 시간, 마을 번호)`를 저장한다.
4. 가장 이동 시간이 짧은 마을부터 꺼내 인접한 마을을 탐색한다.
5. 새로운 경로가 기존 최단 거리보다 짧으면 `distance`를 갱신하고 큐에 추가한다.
6. 모든 탐색이 끝나면 최단 거리가 `K` 이하인 마을의 개수를 반환한다.

- 시간복잡도 : `O((N + M) log(N + M))` — M은 도로의 개수
- 공간복잡도 : `O(N + M)` — 그래프, 거리 배열, 우선순위 큐

### 회고

- **몇 번 만에 성공했는지** : 1회
- **잘한 점** : 그래프를 인접 리스트로 표현하고, 우선순위 큐를 활용해 최단 거리를 갱신하는 구조를 학습했다.
- **개선할 점** : BFS와 다익스트라의 차이를 정확히 구분하고, 가중치가 있는 그래프에서 적절한 알고리즘을 선택하는 연습이 필요하다.
- **새로 배운 점** : 없음
- **느낀 점** : 기존 BFS 문제와 비슷하게 그래프를 탐색하지만, 도로마다 이동 시간이 달라 우선순위 큐가 필요하다는 점이 달랐다.
