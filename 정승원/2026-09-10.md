### 문제 설명
- 문제명: 거꾸로 순열
- 풀이 URL: [거꾸로 순열 — 내 풀이 코드](https://github.com/HappyPotatohappy/CodingTest/blob/main/trail4/거꾸로%20순열/backward-permutation.py)
- 사용 언어: Python
- 1부터 N까지의 숫자를 한 번씩만 사용하여 만들 수 있는 순열을 모두 출력한다.
- 사전순의 반대 순서(내림차순)로 출력한다. 즉 `N N-1 ... 1`이 가장 먼저, `1 2 ... N`이 가장 마지막에 나온다.

### 접근 방식 : 1. 백트래킹 + visited 배열 (선택 순서만 뒤집기)
- 왜 이 방식으로 풀었나?
  - 바로 앞에 푼 「크기가 N인 순열」과 완전히 같은 구조의 문제다. 순열을 만드는 백트래킹 코드는 그대로 두고, 각 자리에서 후보를 고르는 순서만 뒤집으면 된다.
  - `arr`에는 현재까지 선택한 숫자를 저장하고, `visited[i]`는 숫자 `i`가 이미 사용되었는지를 나타낸다.
  - `bt(loc)`의 `loc`은 다음에 채울 자리 번호이며, `bt(1)`부터 시작해 숫자를 하나 고를 때마다 `bt(loc + 1)`을 호출한다.
  - `loc == n + 1`이면 N개의 자리가 모두 채워진 상태이므로 `print(*arr)`로 출력하고 돌아간다.

- 순열을 만드는 방법 -> 이것이 핵심.
  - 각 자리에서 아직 사용하지 않은 숫자(`visited[i] == 0`)만 후보로 삼는다. 이 검사가 "한 번씩만 사용"이라는 순열의 조건을 보장한다.
  - 숫자를 선택하면 `arr.append(i)`, `visited[i] = 1`로 상태를 바꾸고 다음 자리를 재귀적으로 탐색한다.
  - 재귀에서 돌아오면 `arr.pop()`, `visited[i] = 0`으로 선택을 취소하여 다음 후보를 시도하기 전 상태를 복구한다.
  - 중복 순열 문제(K개 중 1개를 N번 뽑기)와의 차이는 `visited` 하나뿐이다. 중복을 허용하면 `visited`가 필요 없고, 허용하지 않으면 필요하다.

- 출력 순서를 뒤집는 방법
  - 오름차순 순열 코드의 `range(1, n + 1)`을 `range(n, 0, -1)`로 바꾸기만 했다.
  - 각 자리에서 큰 숫자부터 시도하므로 첫 번째 자리가 N인 순열이 먼저 완성되고, 그 안에서도 두 번째 자리가 큰 것부터 완성된다. 이것이 정확히 사전순의 역순이다.
  - 따라서 별도의 정렬이나 뒤집기 없이 완성되는 즉시 출력하면 된다.

- 생각해볼 수 있는 다른 방법 -> 비효율적이라 사용하지 않음.
  - 오름차순으로 순열을 전부 만들어 리스트에 저장한 뒤, 리스트를 뒤집어서 출력한다.
  - N!개의 순열을 전부 메모리에 들고 있어야 하므로 공간이 O(N × N!)로 늘어난다. 선택 순서만 바꾸면 되는 문제에서 굳이 저장할 이유가 없다.

- 시간복잡도, 공간복잡도 관점에서의 성능 비교
  - 시간복잡도: **O(N × N!)**
    - 완성되는 순열의 개수는 N!개이고, 순열 하나를 출력하는 데 O(N)이 필요하다.
    - 재귀 트리의 중간 노드(부분 순열)까지 세면 N!/(N−1)! + N!/(N−2)! + ... + N! ≤ e × N! 개이고, 각 노드에서 `range(n, 0, -1)`을 O(N)으로 순회하므로 탐색 비용도 O(N × N!)이다.
    - 오름차순 순열과 방문하는 노드 수가 완전히 같다. 순서만 바뀌었을 뿐 탐색량은 동일하다.
  - 공간복잡도: **O(N)** — 출력 결과를 제외한 보조 공간
    - `arr`은 최대 N개, `visited`는 N + 1개의 원소를 가지며, 재귀 호출 스택도 최대 깊이 N이다.
    - 순열을 저장하지 않고 완성되는 즉시 출력한다.

### 회고
- 몇 번만에 성공했는지: 1번
- 잘한 점:
  - 문제를 새로 푸는 대신, 직전 문제(크기가 N인 순열)의 코드에서 바뀌어야 할 부분이 "후보를 고르는 순서" 하나뿐임을 파악하고 `range`만 수정했다.
  - 각 자리에서 큰 숫자부터 고르면 완성 순서 자체가 사전순 역순이 된다는 점을 이용해, 저장이나 정렬 없이 즉시 출력했다.
  - `append`/`visited[i] = 1`과 `pop`/`visited[i] = 0`을 짝지어 상태 복구를 빠뜨리지 않았다.
- 개선할 점:
  (AI)
  - 오름차순 순열과 코드가 `range` 한 줄만 다르므로, 후보 순서(`range(1, n+1)` 또는 `range(n, 0, -1)`)를 함수 인자로 받게 만들면 두 문제를 하나의 함수로 처리할 수 있다.
