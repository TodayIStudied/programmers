### 문제 설명

- 문제 URL : [미로 탈출](https://school.programmers.co.kr/learn/courses/30/lessons/159993)
- 풀이일 : 2026-11-11
- 미로에서 레버를 당긴 뒤 출구로 나가는 데 필요한 최소 시간을 구하는 문제. 레버나 출구에 도달할 수 없으면 -1을 반환한다.

### 접근 방식 : BFS 두 번

시작점에서 레버까지 가는 거리와 레버에서 출구까지 가는 거리를 따로 구했다. 한 칸 이동할 때 걸리는 시간이 모두 같아서 BFS로 각 구간의 최단거리를 찾으면 된다.

- 미로를 한 번 확인해 시작점, 레버, 출구의 좌표를 찾는다.
- 시작점에서 레버까지 BFS를 돌리고, 레버에서 출구까지 다시 BFS를 돌린다.
- 큐에는 좌표를 넣고, 다음 칸의 거리는 현재 칸의 거리 + 1로 기록한다.
- 벽이나 범위 밖인 칸, 이미 방문한 칸은 건너뛴다.
- 두 구간 중 하나라도 갈 수 없으면 -1을 반환하고, 둘 다 갈 수 있으면 거리를 더한다.

레버를 당긴 뒤에는 이전에 지나온 칸을 다시 지날 수 있다. 그래서 두 번째 BFS에서도 거리 배열을 새로 만들어 각 구간을 독립적으로 탐색했다.

### 복잡도

- R은 미로의 행 수, C는 열 수.
- 시간 : O(R × C). 좌표를 찾고 BFS를 두 번 돌리지만, 각 탐색에서 확인하는 칸 수는 미로 크기에 비례한다.
- 공간 : O(R × C). 거리 배열과 탐색할 좌표를 담는 큐를 사용한다.

### 회고

처음에는 큐에서 좌표를 하나 꺼낼 때마다 count를 늘렸다. 이렇게 하면 이동 거리가 아니라 처리한 칸 수를 세게 된다. 같은 거리의 칸이 여러 개 있어도 하나씩 꺼낼 때마다 숫자가 올라가는 게 문제였다.

각 칸의 거리를 dist 배열에 저장하고, 다음 칸에는 현재 거리 + 1을 넣도록 바꿔 통과했다. BFS로 탐색한 순서와 실제 이동 거리를 구분해야 한다는 점을 기억해두면 좋겠다.
