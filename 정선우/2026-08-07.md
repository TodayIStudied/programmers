# 가장 가까운 같은 글자

## 문제 정보

* 플랫폼: Programmers
* 난이도: Level 1
* 문제 번호: 142086
* 사용 언어: Java
* 분류: 문자열, HashMap

## 문제 요약

문자열 `s`를 왼쪽부터 확인하면서 각 문자에 대해 자신보다 앞에 있는 같은 글자 중 가장 가까운 글자가 몇 칸 떨어져 있는지 구한다.

앞에 같은 글자가 없다면 `-1`을 저장한다.

예를 들어 `banana`에서 두 번째 `a`가 등장했을 때 이전 `a`의 위치와 현재 위치의 차이를 계산한다.

## 문제 접근

처음에는 문자열을 순회하면서 앞에 같은 문자가 존재하는지 확인하려고 했다.

이 문제에서는 단순히 문자의 존재 여부뿐만 아니라 **그 문자가 가장 최근에 등장한 위치**가 필요하다.

따라서 `HashMap`을 사용하여 다음과 같이 저장했다.

```text
문자 → 가장 최근에 등장한 인덱스
```

예를 들어 `banana`를 순회하면 중간 과정에서 다음과 같은 정보가 저장된다.

```text
'b' → 0
'a' → 1
'n' → 2
```

현재 문자가 이전에 등장한 적이 있다면

```text
현재 인덱스 - 이전 인덱스
```

를 계산하고, 처음 등장한 문자라면 `-1`을 저장한다.

마지막으로 현재 문자의 위치를 `HashMap`에 저장하여 가장 최근 위치를 갱신한다.

## 첫 번째 풀이

```java
import java.util.HashMap;

class Solution {
    public int[] solution(String s) {

        int[] answer = new int[s.length()];
        HashMap<Character, Integer> map = new HashMap<>();

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);

            if (map.containsKey(c)) {
                answer[i] = i - map.get(c);
            } else {
                answer[i] = -1;
            }

            map.put(c, i);
        }

        return answer;
    }
}
```

## 코드 설명

### 문자열 순회

```java
for (int i = 0; i < s.length(); i++) {
```

이번 문제에서는 현재 문자의 위치가 필요하므로 향상된 `for`문 대신 인덱스 `i`를 사용할 수 있는 일반 `for`문을 사용했다.

### 문자 가져오기

```java
char c = s.charAt(i);
```

`charAt(i)`를 이용하면 문자열의 `i`번째 문자를 가져올 수 있다.

### 이전에 등장했는지 확인

```java
if (map.containsKey(c)) {
```

`HashMap`에 해당 문자가 존재하면 이전에 등장했던 문자이다.

### 거리 계산

```java
answer[i] = i - map.get(c);
```

`map.get(c)`로 해당 문자가 가장 최근에 등장한 위치를 가져온 뒤 현재 위치 `i`와의 차이를 계산한다.

### 처음 등장한 문자

```java
answer[i] = -1;
```

이전에 등장하지 않았다면 문제의 조건에 따라 `-1`을 저장한다.

### 최근 위치 갱신

```java
map.put(c, i);
```

현재 위치를 저장한다.

이미 존재하는 문자라면 기존 위치가 현재 위치로 덮어써지므로 항상 **가장 최근에 등장한 위치**가 저장된다.

## 더 간결한 풀이

다른 풀이를 확인하면서 `getOrDefault()`를 이용해 조건문을 제거할 수도 있다는 것을 알게 되었다.

```java
import java.util.*;

class Solution {
    public int[] solution(String s) {
        int[] answer = new int[s.length()];
        HashMap<Character, Integer> map = new HashMap<>();

        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);

            answer[i] = i - map.getOrDefault(ch, i + 1);

            map.put(ch, i);
        }

        return answer;
    }
}
```

처음 등장하는 문자라면 `getOrDefault()`의 기본값으로 `i + 1`을 사용한다.

```text
i - (i + 1) = -1
```

따라서 별도의 `if/else` 없이도 처음 등장한 문자의 결과를 `-1`로 만들 수 있다.

이미 등장한 문자라면 기본값은 사용되지 않고 이전 인덱스가 반환되므로

```text
현재 인덱스 - 이전 인덱스
```

가 계산된다.

## 새롭게 배운 내용

### 일반 for문과 향상된 for문

값만 필요할 때는 다음과 같은 향상된 `for`문을 사용할 수 있다.

```java
for (String name : participant) {
}
```

하지만 이번 문제처럼 **현재 위치(index)**가 필요하다면 일반 `for`문이 더 적합하다.

```java
for (int i = 0; i < s.length(); i++) {
}
```

### charAt()

문자열의 특정 위치에 있는 문자를 가져온다.

```java
char c = s.charAt(i);
```

### Character

이번 `HashMap`에서는 하나의 문자를 Key로 사용하므로

```java
HashMap<Character, Integer>
```

를 사용했다.

### HashMap 값 갱신

```java
map.put(c, i);
```

같은 Key에 다시 `put()`하면 기존 Value가 새로운 Value로 변경된다.

이를 이용해 문자의 **가장 최근 등장 위치**를 계속 저장할 수 있다.

## 시간 복잡도

문자열을 한 번 순회한다.

`HashMap`의 `containsKey()`, `get()`, `put()`은 평균적으로 `O(1)`이므로 전체 시간 복잡도는

```text
O(N)
```

이다.

## 공간 복잡도

문자별 마지막 위치를 `HashMap`에 저장하므로 최악의 경우

```text
O(N)
```

의 추가 공간이 필요하다.

## 배운 점

이전 문제에서는 `HashMap`을 이용해

```text
선수 이름 → 등장 횟수
```

를 저장했다.

이번 문제에서는 같은 `HashMap`을

```text
문자 → 마지막으로 등장한 위치
```

형태로 사용했다.

따라서 `HashMap`은 단순히 개수를 세는 자료구조가 아니라 **특정 Key와 관련된 정보를 저장해야 할 때 사용할 수 있다**는 것을 알게 되었다.

또한 처음에는 `containsKey()`를 이용해 직접 조건을 나누어 구현했고, 이후 `getOrDefault()`의 기본값을 `i + 1`로 설정하면 `-1`이 계산되도록 만들 수 있다는 더 간결한 풀이도 배웠다.
