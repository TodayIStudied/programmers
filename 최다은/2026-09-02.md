### 접근 방식 : 1. 수학

* 왜 이 방식으로 풀었나?

  * 처음에는 `x`를 1씩 증가시키면서 각 구간에서 대각선이 지나가는 사각형의 개수를 `ceil`, `floor`를 이용해 직접 계산했다.

  * 하지만 `w`, `h`가 최대 `10^8`이므로 모든 `x`를 순회하는 `O(w)` 방식은 시간 초과가 발생했다.

  * 따라서 대각선이 지나가는 사각형의 개수를 수학적으로 계산하는 방식으로 변경했다.

  * 대각선은 세로 경계선을 `w - 1`번, 가로 경계선을 `h - 1`번 지난다.

  * 시작하는 사각형 1개까지 포함하면 우선 `w + h - 1`개의 사각형을 지난다고 볼 수 있다.

  * 단, 대각선이 격자점을 정확히 지나는 경우에는 가로 경계와 세로 경계를 동시에 통과하므로 하나의 이동을 두 번 계산하게 된다.

  * 대각선이 내부 격자점을 지나는 횟수는 `gcd(w, h) - 1`번이다.

  * 따라서 대각선 때문에 사용할 수 없는 사각형의 개수는 다음과 같다.

    `w + h - 1 - (gcd(w, h) - 1) = w + h - gcd(w, h)`

  * 전체 사각형 `w * h`에서 해당 값을 제외하여 답을 구했다.

  ```python
    import math
    
    def solution(w, h):
        cut = w + h - math.gcd(w, h)
        return w * h - cut
  ```

* 시간복잡도, 공간복잡도 관점에서의 성능 비교

  * 기존 풀이

    * 시간복잡도: `O(w)`
    * `w`가 최대 `10^8`까지 가능하므로 시간 초과가 발생할 수 있다.
  * 개선 풀이

    * 시간복잡도: `O(log(min(w, h)))`

      * 유클리드 호제법을 사용하는 `gcd` 계산 비용
    * 공간복잡도: `O(1)`
  * 제출 결과

    * 메모리: 11.4 MB
    * 시간: 0.00 ms
