### 접근 방식 : 1. 반복문?
```
N = len(board)
dx = [-1,-1,-1,0,0,1,1,1]
dy = [-1,0,1,1,-1,1,-1,0]

boom = []
for i in range(N):
    for j in range(N):
        if board[i][j] == 1:
            boom.append((i,j))

count = 0
for x, y in boom:
    for i in range(8):
        nx = x + dx[i]
        ny = x y dy[i]

        if 0 <= nx < N and 0 <= ny < N:
            board[nx][ny] = 1

count = 0
for x in range(N):
    for y in range(N):
        if board[x][y] == 1:
            count += 1

return count
```

그냥 모르겠어서 외웠다 !!!

- 돌면서 폭탄의 위치 추가
- 돌아봐야 할 가로방향, 세로방향의 (nx, ny) 설정
- 돌은 좌표 내 폭탄이 설치된 좌표 1로 표시
- 폭탄 없는 좌표 (0) count

표시되지 않은 곳의 count 의 구조!!
