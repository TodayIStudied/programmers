### 접근 방식 : 비트 OR 연산 + 문자열 처리
- 문제에서 `0과 1`, `둘 중 하나 혹은 둘 다`, 최대 16자리 등의 조건을 보고 이진수와 비트 연산을 사용하는 문제라고 생각했다.
- 두 지도를 각각 이진수로 변환해서 비교하려고 했지만, 숫자 상태에서 바로 OR 연산을 한 뒤 결과만 이진수 문자열로 변환하는 것이 더 간단하다는 것을 알게 되었다.
- OR 연산 결과를 문자열로 변환한 뒤 `#`과 공백으로 치환하여 지도를 완성했다.

### 트러블슈팅

#### 1. int를 이진수로 어떻게 변환하지?
풀이 방법은 떠올렸지만 Java에서 정수를 이진수로 표현하는 방법을 몰랐다.

```java
Integer.toBinaryString(number);
```

을 사용하면 정수를 이진수 문자열로 변환할 수 있다는 것을 알게 되었다.

#### 2. OR 연산 전에 이진수 문자열로 변환해야 하나?
처음에는 다음과 같이 생각했다.

```text
숫자 → 이진수 문자열 변환 → OR 연산
```

하지만 `int`는 내부적으로 비트로 표현되므로 숫자 상태에서 바로 비트 연산이 가능했다.

```java
arr1[i] | arr2[i]
```

따라서 실제로는:

```text
숫자끼리 비트 OR → 결과만 이진수 문자열로 변환
```

하면 된다.

또한 `||`는 논리 OR, `|`는 비트 OR라는 차이도 알게 되었다.

#### 3. 부족한 이진수 자릿수를 어떻게 채우지?
`Integer.toBinaryString()`은 앞의 `0`을 생략하기 때문에 `n`보다 짧은 문자열이 나올 수 있었다.

예를 들어:

```text
n = 5
9 → "1001"
```

처음에는 `"01001"`처럼 앞에 `0`을 추가해야 한다고 생각했다.

하지만 최종적으로 `0`은 공백으로 바꿔야 하므로 처음부터 부족한 자리를 공백으로 채워도 결과가 같았다.

```java
String.format("%" + n + "s", binary);
```

`%5s`는 문자열이 최소 5자리가 되도록 왼쪽을 공백으로 채워준다.

#### 4. 배열에 값을 어떻게 추가하지?
처음에는 다음과 같이 작성했다.

```java
answer.put(result);
```

하지만 `put()`은 주로 `Map`에서 `key-value`를 저장할 때 사용한다.

배열은 크기를 먼저 지정하고 인덱스로 값을 저장해야 한다.

```java
String[] answer = new String[n];

answer[i] = result;
```

자료구조별 값 추가 방법도 다시 정리했다.

```text
배열 → arr[i] = value
List → add(value)
Set  → add(value)
Map  → put(key, value)
```

### 오늘 배운 개념
- `Integer.toBinaryString()`을 이용한 정수 → 이진수 문자열 변환
- `|`를 이용한 비트 OR 연산
- `String.format()`을 이용한 문자열 자릿수 맞추기
- `replace()`를 이용한 문자열 치환
- 배열과 `List`, `Set`, `Map`의 값 저장 방식 차이

- 알고리즘 자체보다는 Java에서 이진수 변환, 문자열 자릿수 처리, 배열에 값을 저장하는 문법에서 더 많이 막혔다.
