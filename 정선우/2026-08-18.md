# 가장 큰 수

## 문제 정보

- 플랫폼: Programmers
- 난이도: Level 2
- 문제 번호: 42746
- 사용 언어: Java
- 분류: 정렬

---

## 풀이 코드

```java
import java.util.Arrays;

class Solution {
    public String solution(int[] numbers) {

        String[] nums = new String[numbers.length];

        // 숫자를 문자열로 변환
        for (int i = 0; i < numbers.length; i++) {
            nums[i] = String.valueOf(numbers[i]);
        }

        // 두 숫자를 붙였을 때 더 큰 수가 만들어지는 순서로 정렬
        Arrays.sort(nums, (a, b) -> {
            String ab = a + b;
            String ba = b + a;

            return ba.compareTo(ab);
        });

        // 가장 앞의 값이 0이라면 모든 숫자가 0
        if (nums[0].equals("0")) {
            return "0";
        }

        // 정렬된 문자열 연결
        StringBuilder sb = new StringBuilder();

        for (String num : nums) {
            sb.append(num);
        }

        return sb.toString();
    }
}
```

# 오늘 배운 것

## 1. 기본 정렬과 사용자 정의 정렬

이전 문제에서는 단순히 오름차순 정렬을 사용했다.

```java
Arrays.sort(array);
```

하지만 이번 문제에서는 숫자 자체의 크기순으로 정렬하면 원하는 결과를 만들 수 없다.

예를 들어

```text
3, 30
```

을 단순히 숫자로 비교하면 `30`이 더 크다.

하지만 두 숫자를 이어 붙이면

```text
3 + 30  → 330
30 + 3  → 303
```

이므로 가장 큰 수를 만들기 위해서는 `3`이 `30`보다 앞에 있어야 한다.

따라서 이번에는 Java의 기본 정렬 기준이 아니라 **직접 만든 정렬 기준**이 필요했다.

```java
Arrays.sort(nums, (a, b) -> {
    ...
});
```

정리하면

```text
Arrays.sort(array)
→ Java의 기본 기준으로 정렬

Arrays.sort(array, comparator)
→ 내가 지정한 기준으로 정렬
```

---

## 2. Comparator의 역할

이번 문제에서 가장 중요하게 배운 부분이다.

Comparator가 전체 배열을 직접 정렬하는 것이 아니다.

역할을 나누면 다음과 같다.

```text
Arrays.sort()
→ 전체 정렬을 담당

Comparator
→ 두 값이 주어졌을 때 누가 앞에 올지 판단
```

예를 들어

```java
Arrays.sort(nums, (a, b) -> {
    ...
});
```

에서 `Arrays.sort()`가 정렬 과정에서 비교가 필요한 두 값을 `a`, `b`로 전달한다.

```text
a = "3"
b = "30"
```

Comparator는 이 두 값의 순서만 판단하면 된다.

그 결과를 이용해서 `Arrays.sort()`가 전체 배열을 정렬한다.

### 중요한 점

Comparator는 한 번에 **두 값만 비교한다.**

하지만 `Arrays.sort()`가 정렬 과정에서 Comparator를 필요한 만큼 반복해서 호출한다.

따라서 우리가

```text
1등 찾기
2등 찾기
3등 찾기
...
```

를 직접 구현할 필요가 없다.

또한 Comparator가 비교 결과를 별도의 캐시에 저장하는 것이 아니라, `Arrays.sort()`가 비교 결과를 이용해 정렬 과정을 진행한다.

---

## 3. `(a, b) ->` 람다식

이번 문제에서 처음으로 다음 문법을 사용했다.

```java
(a, b) -> {
}
```

이 문법을 람다식이라고 한다.

이번 문제에서는 우선 다음과 같이 이해했다.

```text
a, b
→ Arrays.sort()가 비교를 위해 전달한 두 값

->
→ 이 두 값을 가지고 다음 코드를 실행
```

즉,

```java
Arrays.sort(nums, (a, b) -> {
    ...
});
```

는

```text
nums를 정렬하는데
두 값 a, b를 비교할 때
내가 작성한 규칙을 사용한다.
```

라고 이해할 수 있다.

`a`, `b`라는 변수명은 정해져 있는 것이 아니다.

예를 들어 다음처럼 작성해도 같은 의미이다.

```java
Arrays.sort(nums, (x, y) -> {
    ...
});
```

`nums`가 `String[]`이므로 Java가 `a`, `b` 역시 String이라는 것을 추론한다.

---

## 4. 숫자를 String으로 변환하기

이번 문제에서는 숫자를 더하는 것이 아니라 **이어 붙여서 비교**해야 했다.

숫자 상태에서

```java
3 + 30
```

을 하면

```text
33
```

이 된다.

하지만 문자열 상태에서

```java
"3" + "30"
```

을 하면

```text
"330"
```

이 된다.

따라서 `int`를 `String`으로 변환했다.

```java
String.valueOf(numbers[i]);
```

전체 배열을 변환하기 위해

```java
String[] nums = new String[numbers.length];

for (int i = 0; i < numbers.length; i++) {
    nums[i] = String.valueOf(numbers[i]);
}
```

를 사용했다.

결과:

```text
numbers = [3, 30, 34, 5, 9]

↓

nums = ["3", "30", "34", "5", "9"]
```

---

## 5. 두 숫자의 순서를 붙여서 비교하기

이번 문제의 핵심 정렬 기준은 다음과 같다.

두 문자열 `a`, `b`가 있을 때

```java
String ab = a + b;
String ba = b + a;
```

두 가지 경우를 만들어본다.

예를 들어

```text
a = "3"
b = "30"
```

이면

```text
ab = "330"
ba = "303"
```

이다.

`330`이 더 크기 때문에

```text
"3" → "30"
```

순서로 정렬해야 한다.

다른 예로

```text
a = "3"
b = "34"
```

이면

```text
ab = "334"
ba = "343"
```

이므로

```text
"34" → "3"
```

순서가 되어야 한다.

중요한 점은 `ab`, `ba` 자체를 배열에 저장하는 것이 아니라는 것이다.

```text
a와 b
→ 실제 정렬 대상

ab와 ba
→ a와 b의 순서를 판단하기 위한 임시 비교값
```

## 6. compareTo()

문자열의 순서를 비교하기 위해 `compareTo()`를 사용했다.

```java
문자열1.compareTo(문자열2)
```

결과는 `true`, `false`가 아니라 정수이다.

```text
음수
0
양수
```

Comparator에서는 이 결과를 이용해 두 값의 정렬 순서를 판단한다.

이번 문제에서는 큰 숫자를 만드는 순서가 앞으로 와야 하므로

```java
return ba.compareTo(ab);
```

를 사용했다.

전체 정렬 기준은 다음과 같다.

```java
Arrays.sort(nums, (a, b) -> {

    String ab = a + b;
    String ba = b + a;

    return ba.compareTo(ab);
});
```

즉,

```text
a를 먼저 붙였을 때
vs
b를 먼저 붙였을 때
```

를 비교해서 더 큰 수가 만들어지는 순서로 정렬한다.

---

## 7. 모든 숫자 쌍을 직접 비교하지 않아도 되는 이유

처음에는 모든 숫자를 직접 앞뒤로 비교해야 하는지 헷갈렸다.

하지만 Comparator는 모든 조합을 직접 반복문으로 비교하는 것이 아니다.

```text
Comparator
→ 두 값의 순서를 판단하는 규칙만 제공

Arrays.sort()
→ 그 규칙을 이용해 필요한 비교를 수행
```

따라서 우리가 직접

```text
3 vs 30
3 vs 34
3 vs 5
3 vs 9
30 vs 34
30 vs 5
...
```

처럼 모든 조합을 작성할 필요가 없다.

`Arrays.sort()`가 내부 정렬 알고리즘을 이용해 필요한 비교를 수행하고 최종 순서를 만든다.

---

## 8. Arrays.sort()는 원본 배열을 변경한다

이전 정렬 문제에서 배운 내용과 연결된다.

```java
Arrays.sort(nums, comparator);
```

를 실행하면 새로운 배열을 반환하는 것이 아니라 `nums` 자체의 순서가 변경된다.

예를 들어

```text
Before

["5", "9", "3", "34", "30"]
```

정렬 후에는

```text
After

["9", "5", "34", "3", "30"]
```

이 된다.

Comparator는 순서만 판단하고, 실제 정렬은 `Arrays.sort()`가 수행한다.

## 9. StringBuilder

처음에는 정렬된 문자열을 다음과 같이 합쳤다.

```java
String answer = "";

for (String num : nums) {
    answer += num;
}
```

결과 자체는 정상적으로 나온다.

하지만 Java의 `String`은 **불변(Immutable)** 객체이다.

즉,

```java
answer += num;
```

을 반복하면 기존 String에 값을 직접 추가하는 것이 아니라 새로운 String 객체가 계속 만들어질 수 있다.

문자열을 반복해서 연결할 때는 `StringBuilder`를 사용하는 것이 효율적이다.

```java
StringBuilder sb = new StringBuilder();

for (String num : nums) {
    sb.append(num);
}
```

문자열을 추가할 때는

```java
sb.append(num);
```

을 사용한다.

마지막에 String으로 변환한다.

```java
return sb.toString();
```

정리하면

```text
문자열 몇 개를 간단하게 연결
→ +

반복문에서 문자열을 계속 연결
→ StringBuilder
```

로 생각할 수 있다.

## 10. 0 예외 처리

입력이

```text
[0, 0, 0]
```

이라면 문자열을 모두 합쳤을 때

```text
"000"
```

이 된다.

하지만 문제에서 원하는 결과는

```text
"0"
```

이다.

정렬이 끝난 후 가장 앞의 값이 `"0"`이라면 가장 큰 값조차 0이라는 뜻이므로 모든 값이 0이다.

따라서

```java
if (nums[0].equals("0")) {
    return "0";
}
```

으로 처리할 수 있다.

# 오늘의 핵심 정리

오늘은 오름차순 정렬에서 한 단계 더 나아가 **정렬 기준을 직접 만드는 방법**을 배웠다.

가장 중요하게 이해한 것은 `Arrays.sort()`와 Comparator의 역할 차이이다.

```text
Arrays.sort()
→ 전체 정렬 담당

Comparator
→ 두 값 중 누가 앞에 올지 판단
```

이번 문제에서는 숫자 자체를 비교하는 것이 아니라

```text
a + b
b + a
```

두 경우를 비교하여 더 큰 숫자를 만들 수 있는 순서를 정렬 기준으로 사용했다.

또한 처음으로

```java
(a, b) -> { }
```

형태의 람다식을 사용했고, 문자열 비교를 위한 `compareTo()`도 배웠다.

마지막으로 문자열을 반복해서 연결할 때

```java
answer += num;
```

보다

```java
StringBuilder
```

를 사용하는 방법도 새롭게 배웠다.

오늘의 가장 중요한 개념은

```text
정렬을 직접 구현하는 것이 아니라
"어떤 값이 앞에 와야 하는가"라는 규칙만 만들고
실제 전체 정렬은 Arrays.sort()에게 맡길 수 있다.
```

는 것이다.
