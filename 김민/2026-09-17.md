### 문제 설명  
- 풀이 URL : [n + 1 카드게임](https://github.com/MK513/Algorithm/tree/main/%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%98%EB%A8%B8%EC%8A%A4/3/258707.%E2%80%85n%E2%80%85%EF%BC%8B%E2%80%851%E2%80%85%EC%B9%B4%EB%93%9C%EA%B2%8C%EC%9E%84)

### 접근 방식 : 1. 그리디
- 카드를 뽑을 때마다 즉시 코인을 지불하지 않고, 상태를 기록해둔 뒤 합이 `n + 1`이 되는 쌍이 발견되면 코인을 지불하는 지연 결제(가불) 방식을 고안했다.
- 다만, 합이 맞는 쌍을 발견하는 즉시 코인을 소모하게 짜여 있어서 일부 테스트 케이스에서 실패했다.
- 코인 0개로 낼 수 있는 '초기 카드 쌍'을 놔두고, 코인 2개가 드는 '뽑은 카드 쌍'을 먼저 내버리면서 정작 필요할 때 코인이 고갈되는 문제가 발생했기 때문이다.

### 접근 방식 : 2. 코인 소모 최소화 그리디 (비용 기준 우선순위 정렬)
- 합이 `n + 1`이 되는 쌍들을 구조체로 묶어 후보 배열에 담고, 각 쌍을 내는 데 필요한 코인 비용(`debts` 합)을 기준으로 오름차순 정렬하여 코인을 가장 적게 쓰는 짝부터 처리하도록 로직을 개선했다.
- 0코인 -> 1코인 -> 2코인 소모 순으로 카드를 내게 되므로 코인 낭비를 완벽히 막을 수 있었고, 문제의 핵심 의도인 그리디 알고리즘에 정확히 부합했다.

### 회고

- 개선할 점 : 비용 기준 우선 순위는 미쳐 떠올리지 못함
