### 접근 방식 : 1. 투 포인터 + 그리디
- 왜 이 방식으로 풀었나?
  - 처음에 오름차순 정렬 후 앞에서부터 묶어서 limit보다 작으면 삭제하도록 구현했음
  - 그런데 이 방식이 항상 가장 작은 개수임을 보장하기가 어려움.
  - 그래서 가장 무거운 사람과 가장 가벼운 사람을 함께 태울 수 있는지 투 포인터로 확인하는 걸 그리디로 구현
  ```python
def solution(people, limit):
    people.sort()

    left = 0
    right = len(people) - 1
    answer = 0

    while left <= right:
        if people[left] + people[right] <= limit:
            left += 1

        right -= 1
        answer += 1

    return answer

  ```
- 시간복잡도, 공간복잡도 관점에서의 성능 비교
