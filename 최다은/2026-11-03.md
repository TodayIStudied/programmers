### 접근 방식 : 1. DP
- 왜 이 방식으로 풀었나?
  - n칸에 도달하는 마지막 이동은 1칸 또는 2칸이므로, 각각 n-1칸과 n-2칸까지 도달하는 경우의 수 합
  - 점화식 dp[i] = dp[i-1] + dp[i-2]
  - 수 초과 없도록 매 단계 1234567로 나눈 나머지를 저장
```python
def solution(n):
    dp = [0 for _ in range(n+1)]
    dp[0], dp[1] = 1, 1

    for i in range(2,n+1):
        dp[i] = (dp[i-1]+dp[i-2])%1234567

    return dp[n]
```
- 시간복잡도, 공간복잡도 관점에서의 성능 비교
  - 제출 결과 : 메모리 11.1 MB, 시간 0.25 ms
