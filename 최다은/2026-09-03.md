### 접근 방식 : 1. BFS 
- 왜 이 방식으로 풀었나?
  - 아주 기본적인 BFS임.
  - 최단거리가 반드시 보장되며 최단거리 나오자마자 return해도 되기에 큐에 (현재 행, 현재 열, 지금까지 거리) 넣으면 됨.
  - 그리고 거리도 모두 1로 같아서 그냥 다 넣고 돌리다가 최단 거리 나오면 종료시키는 것 
 
    ```python
      import sys 
      from collections import deque 
  
      def solution(maps):
          n = len(maps)
          m = len(maps[0])
          def bfs():
              dr = [1,-1,0,0]
              dc = [0,0,1,-1]
              
              queue = deque()
              queue.append((0,0,1))
          
              visited = [[False for _ in range(m)] for _ in range(n)]
              visited[0][0] = True
              
              while(queue):
                  cr,cc,dist = queue.popleft() 
                  if(cr==n-1 and cc==m-1):
                      return dist
                  
                  for i in range(4):
                      nr = cr + dr[i]
                      nc = cc + dc[i]
                      
                      if(0<=nr<n and 0<=nc<m and visited[nr][nc]==False and maps[nr][nc]==1):
                          visited[nr][nc]=True 
                          queue.append((nr,nc,dist+1))
              return -1 
                      
          return bfs()
    ```
