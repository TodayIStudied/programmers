# 완주하지 못한 선수

## 문제 정보

* 플랫폼: Programmers
* 난이도: Level 1
* 문제 번호: 42576
* 사용 언어: Java
* 분류: 해시(Hash)

## 문제 요약

마라톤에 참여한 선수 중 단 한 명을 제외하고 모든 선수가 완주했다.

`participant`에는 참가자의 이름이, `completion`에는 완주자의 이름이 주어진다.

참가자 중에는 동명이인이 존재할 수 있으므로 단순히 이름의 존재 여부만 확인하는 것이 아니라, 각 이름이 몇 번 등장했는지도 확인해야 한다.

## 문제 접근

처음에는 완주하지 못한 사람은 참가자 명단에 남아 있을 것이라고 생각했다.

하지만 동명이인이 존재할 수 있기 때문에 `HashSet`처럼 중복을 제거하는 자료구조는 사용할 수 없다.

따라서 선수의 이름과 해당 이름을 가진 참가자의 수를 함께 저장할 수 있는 `HashMap`을 사용했다.

```text
mislav → 2
stanko → 1
ana    → 1
```

먼저 `participant`를 순회하면서 각 이름의 등장 횟수를 저장한다.

그다음 `completion`을 순회하면서 완주한 선수의 등장 횟수를 1씩 감소시킨다.

모든 완주자를 처리한 뒤 값이 `1`로 남아 있는 선수가 완주하지 못한 선수이다.

## 풀이 코드

```java
import java.util.HashMap;

class Solution {
    public String solution(String[] participant, String[] completion) {
        String answer = "";

        HashMap<String, Integer> map = new HashMap<>();

        for (String name : participant) {
            if (map.containsKey(name)) {
                map.put(name, map.get(name) + 1);
            } else {
                map.put(name, 1);
            }
        }

        for (String name : completion) {
            map.put(name, map.get(name) - 1);
        }

        for (String name : map.keySet()) {
            if (map.get(name) == 1) {
                answer = name;
                break;
            }
        }

        return answer;
    }
}
```

## HashMap

`HashMap`은 데이터를 `Key → Value` 형태로 저장하는 자료구조이다.

이번 문제에서는 다음과 같이 사용했다.

```text
선수 이름(String) → 참가자 수(Integer)
```

### 생성

```java
HashMap<String, Integer> map = new HashMap<>();
```

### 값 저장 및 수정

```java
map.put(key, value);
```

### 값 가져오기

```java
map.get(key);
```

### Key 존재 여부 확인

```java
map.containsKey(key);
```

### 모든 Key 가져오기

```java
map.keySet();
```

## 새롭게 알게 된 getOrDefault()

풀이 후 다른 풀이를 확인하면서 `getOrDefault()` 메서드도 알게 되었다.

기존 코드는 다음과 같다.

```java
if (map.containsKey(name)) {
    map.put(name, map.get(name) + 1);
} else {
    map.put(name, 1);
}
```

`getOrDefault()`를 사용하면 다음처럼 줄일 수 있다.

```java
map.put(name, map.getOrDefault(name, 0) + 1);
```

`getOrDefault(key, defaultValue)`는 Key가 존재하면 기존 Value를 반환하고, 존재하지 않으면 지정한 기본값을 반환한다.

따라서 등장 횟수를 세는 문제에서 유용하게 사용할 수 있다.

## 시간 복잡도

참가자 배열을 한 번 순회한다.

```text
O(N)
```

완주자 배열도 한 번 순회한다.

```text
O(N)
```

마지막으로 `HashMap`의 Key를 순회한다.

따라서 전체 시간 복잡도는 평균적으로:

```text
O(N)
```

이다.

`HashMap`의 `put()`, `get()`, `containsKey()`는 평균적으로 `O(1)`이다.

## 공간 복잡도

참가자의 이름을 `HashMap`에 저장하므로 최악의 경우:

```text
O(N)
```

의 추가 공간이 필요하다.

## HashSet과 HashMap 차이

Day 1에서는 `HashSet`을 사용했다.

```text
HashSet
→ 값만 저장
→ 중복을 허용하지 않음
→ 서로 다른 값이 중요한 경우
```

Day 2에서는 `HashMap`을 사용했다.

```text
HashMap
→ Key와 Value를 함께 저장
→ Key에 대응하는 정보를 저장할 수 있음
→ 등장 횟수 등을 기록할 때 유용
```

따라서 앞으로 문제를 볼 때:

```text
중복 제거 / 고유한 값
→ Set을 먼저 생각

값별 개수 / 값에 대응하는 정보
→ Map을 먼저 생각
```

하는 습관을 가져야겠다.

## 배운 점

처음에는 완주하지 못한 사람이 참가자 명단에 남는다는 점을 이용하면 된다고 생각했다.

하지만 동명이인 조건 때문에 단순히 이름의 존재 여부만 확인해서는 안 된다는 것을 알게 되었다.

이를 해결하기 위해 `HashMap`에 `선수 이름 → 등장 횟수`를 저장했고, 완주자의 수를 하나씩 감소시켜 최종적으로 남은 선수를 찾았다.

또한 `containsKey()`와 `get()`을 사용해 직접 조건을 처리한 뒤, `getOrDefault()`를 사용하면 동일한 로직을 더 간결하게 표현할 수 있다는 것도 배웠다.
