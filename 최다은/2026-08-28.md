### 접근 방식 : 리스트 자구로 LRU 캐시 구현 

- 왜 이 방식으로 풀었나?
  - LRU 캐시는 캐시 존재하면 순서 변경하고 없으면 자신을 추가하고 다른 원소 탈락시킴 ..
  - 해시 자료구조인 DICT로 고민해봤으나 true/false 관리해 비용 많이 들음.
  - 리스트 기반으로 LRU 구현하는 것이 가장 깔끔하다.
  ```
  def solution(cacheSize, cities):
      answer = 0  
      if(cacheSize==0): return 5*len(cities)
      cities = [city.lower() for city in cities]
      cache = []
      for i in range(len(cities)):
          city = cities[i]
          if city in cache:
              cache.remove(city)
              cache.append(city)
              answer += 1
          else:
              if len(cache)!=0 and len(cache)>=cacheSize:
                  del cache[0]
              cache.append(city)
              answer += 5
      return answer
"""
1. for문 순회 
2. 원소가 캐시에 존재하는지 검사
    2.1 존재한다면 원소 캐시 순서 가장 위로 변경 && answer += 1
    2.2 존재하지 않는다면 가장 마지막 원소 제거 && 캐시 삽입 && answer += 5
"""
  ```
