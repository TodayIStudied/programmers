# 프로그래머스 Lv.3 — 네트워크

### 문제 설명
- 풀이 URL : [네트워크](https://github.com/sunoo2468/codingTestPre/blob/main/Python/%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%98%EB%A8%B8%EC%8A%A4/3/43162.%E2%80%85%EB%84%A4%ED%8A%B8%EC%9B%8C%ED%81%AC/%EB%84%A4%ED%8A%B8%EC%9B%8C%ED%81%AC.py)
- 난이도 : Lv.3
- 알고리즘 : DFS, 그래프 탐색, 인접 행렬

### 접근 방식 : DFS + 방문 처리

1. `visited` 배열을 이용해 각 컴퓨터의 방문 여부를 관리한다.
2. 연결되어 있고 아직 방문하지 않은 컴퓨터를 스택에 추가한다.
3. 방문하지 않은 컴퓨터에서 새로운 DFS를 시작할 때마다 `answer`를 1 증가시킨다.
4. 모든 컴퓨터의 탐색이 끝나면 네트워크 개수를 반환한다.

- 시간복잡도 : `O(N²)` — 각 컴퓨터의 연결 관계를 인접 행렬에서 확인한다.
- 공간복잡도 : `O(N)` — 방문 배열과 DFS 스택을 사용한다.

### 회고

- **몇 번 만에 성공했는지** : 1회

- **잘한 점**
  - DFS는 연결된 컴퓨터를 방문 처리하는 역할을 담당하고, 외부 반복문은 새로운 네트워크의 개수를 계산하도록 구성했다.
  
- **개선할 점**
  - 인접 행렬에서 연결 관계를 확인하는 방식과 인접 리스트를 사용하는 방식의 차이를 이해할 필요가 있다.
  - 문제의 입력 규모에 따라 재귀 DFS와 반복 DFS 중 적절한 구현 방식을 선택하는 능력을 키워야 한다.

- **새로 배운 점**
  - 그래프에서 서로 연결된 노드들의 집합을 연결 요소(Connected Component)라고 한다.
  - 방문하지 않은 노드에서 DFS를 새로 시작하는 횟수가 연결 요소의 개수가 된다.
  - 인접 행렬에서는 `computers[current][next_node]`를 통해 두 컴퓨터의 연결 여부를 확인할 수 있다.
  - 스택을 이용한 반복 DFS는 재귀 호출 없이도 연결된 모든 노드를 탐색할 수 있다.

- **느낀 점**
  - 무인도 여행과 혼자 놀기의 달인에 이어, DFS를 활용해 연결된 컴퓨터들을 그룹으로 구분하는 문제를 학습했다.
  - 문제마다 데이터의 형태는 달랐지만, 방문하지 않은 노드에서 탐색을 시작하고 연결된 노드를 모두 방문한다는 공통적인 구조를 확인할 수 있었다.
