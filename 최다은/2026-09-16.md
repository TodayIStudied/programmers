### 접근 방식 : 1. 구현
- 왜 이 방식으로 풀었나?
  - 그냥 문제 설명대로 풀면 됨.
  - enumerate 사용해서 index와 원소 동시에 큐에 넣어두고
  - 하나씩 popleft해서 실제로 비교 수행하면서 조건 만족할 때까지 반복하기
  - 한 번에 heapq 정렬 등으로 답을 찾을 수는 없음
  - 조건이 순차적으로 훑으며 확인하는 것이기에 max num이 계속 변경됨.
  - 이 max num을 줄이려고 고민해봤는데 사실.,,, n이 너무 작아서 그냥 순회해도 괜찮음.. 
  
  ```python
      from collections import deque
      
      def solution(priorities, location):
          queue = deque((p, i) for i, p in enumerate(priorities))
          cnt = 0
      
          while queue:
              curr_p, curr_i = queue.popleft()
      
              if any(curr_p < p for p, _ in queue):
                  queue.append((curr_p, curr_i))
              else:
                  cnt += 1
      
                  if curr_i == location:
                      return cnt
  ```
- 시간복잡도, 공간복잡도 관점에서의 성능 비교
