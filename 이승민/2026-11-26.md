### 접근 방식 : 1. 그리디 / 수학 (몫과 나머지)
- 왜 이 방식으로 풀었나?
  - 최소 개미 수를 구해야 하므로 공격력이 가장 큰 장군개미(5)부터 최대로 사용하는 그리디 방식 적용
  - 5로 나눈 몫을 결과에 누적하고 나머지를 다음 체력으로 갱신
  - 남은 체력을 병정개미(3)로 나눈 몫을 더하고, 최종 나머지(1)를 일개미 수로 합산 반환
- 시간복잡도, 공간복잡도 관점에서의 성능 비교 
  - 시간복잡도: O(1) (단순 사칙연산만 수행하므로 즉시 종료)
  - 공간복잡도: O(1) (추가 메모리 없이 변수 하나로 해결)
  - 정확성 테스트 통과 (0.01ms 내외)

### 회고 
- 몇 번만에 성공했는지 : 1번
- 잘한 점 : 몫(//)과 나머지(%) 연산으로 공격력 큰 순서대로 깔끔하게 카운트한 점
- 개선할 점 : `divmod()` 함수를 쓰거나 `hp // 5 + (hp % 5) // 3 + (hp % 5) % 3`처럼 한 줄 수식으로 줄이면 변수 재할당 없이 더 간결해짐
