### 접근 방식 : 1. 구현 
- 왜 이 방식으로 풀었나?
  - 단순 구현임.
  - 문제에서 제시한 것의 역순으로 사전 구성해서 알파벳으로 색인 접근하면 됨.
  - msg 길이 1000 이하라서 시간 복잡도 부담 적은 O(N^2) 아래이기만 하면 괜찮음
  - 시작하는 문자열마다 사전에 존재하는 가장 긴 문자열 찾기 위해 탐색 필요 < O(N^2)
  - 단순 구현이기는 한데 고려해야 할 조건이 좀 있는 편?
  - defaultdict 사용해서 None 처리 쉽게 구현.
    ```python
    from collections import defaultdict 
    def solution(msg):
        
        alpha = defaultdict()
        for i in range(26):
            alpha[chr(i+65)]=i+1 
            
        answer = []
        start = 0
        idx = 27
        
        while(start<len(msg)):
            length =1
            
            while(start+length<=len(msg) and alpha.get(msg[start:start+length]) is not None):
                length += 1
            answer.append(alpha.get(msg[start:start+length-1]))
            #print(start,msg[start:start+length-1],msg[start:start+length])
            if alpha.get(msg[start:start+length]) is None:
                alpha[msg[start:start+length]] = idx
            start = start+length -1 
            idx+=1
            
        return answer
    
    ```
- 시간복잡도, 공간복잡도 관점에서의 성능 비교
  - 메모리: 11.5 MB, 시간: 0.34 ms
