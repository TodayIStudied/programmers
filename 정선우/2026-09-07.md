### 접근 방식 : 구현
- 왜 이 방식으로 풀었나?
  - 숫자가 `1, 2, 4`의 규칙으로 반복되는 것을 보고, 3으로 계속 나누면서 몫과 나머지를 이용하는 방식으로 접근했다.
  - 나머지가 `0`일 때는 일반적인 3진법과 다르게 별도의 처리가 필요하다는 점까지 파악했다.
  - 나머지를 이용해 만들어지는 숫자는 뒤에서부터 결정되므로 마지막에 문자열을 뒤집어 결과를 완성한다.

### 회고
- 몇 번만에 성공했는지 : 직접 구현(2회) 후 도움을 받아 해결

- 잘한 점 :
  - 지금까지 풀었던 문제 중 가장 오랫동안 혼자 고민한 문제였다.
  - `1, 2, 4`의 반복을 보고 3으로 나눈 몫과 나머지를 이용해야 한다는 규칙을 스스로 찾았다.
  - 완성하지는 못했지만 직접 작성한 코드로 테스트 케이스를 2개 통과했다.
  - 이전 문제들에 비해 문제의 규칙을 찾고 코드로 옮기는 과정까지 혼자 진행한 부분이 많아졌다는 점은 발전한 부분이라고 생각한다.

- 개선할 점 :
  - 계산 과정에서 숫자가 뒤에서부터 만들어진다는 것을 확인했지만, 결과를 만든 뒤 문자열을 뒤집으면 된다는 생각을 하지 못했다.
  - **처음부터 정답 문자열을 올바른 방향으로 만들어야 한다는 생각에 너무 고정되어 있었다.**
  - `answer[::-1]`처럼 일단 편한 방향으로 결과를 만든 뒤 마지막에 뒤집는 방법도 있다는 것을 기억해야겠다.
  - 앞으로는 구현 과정이 복잡해질 때 처음 생각한 방식만 고집하지 말고, **중간 결과를 만든 후 마지막에 가공하는 방법은 없는지**도 생각해봐야겠다.
  - 접근 방법을 스스로 찾은 만큼 다음에는 예외 처리와 구현까지 혼자 완성할 수 있도록 더 연습해야겠다.
