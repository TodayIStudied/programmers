### 접근 방식 : 2. 점화식이라고 봐야할지..? 
- 왜 이 방식으로 풀었나?
  - 처음에 DP 떠올렸다가
  - 공간 낭비할 필요없이 변수 2개만 있으면 되기 때문에
  - 그냥.. 점화식으로 풀었음.
```python
  def solution(n):
      DIV = 1234567
  
      if n==2:
          return 1
      
      p0 = 1
      p1 = 2
  
      for _ in range(3, n + 1):
          p0, p1 = p1, (p0 + p1) % DIV
  
      return p0
```
- 시간복잡도, 공간복잡도 관점에서의 성능 비교
  - 메모리: 11.3 MB, 시간: 4.74 ms
