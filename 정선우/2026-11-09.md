- 학습 목표 : DFS 탐색 결과를 재사용하여 중복 연산 최소화

### 접근 방식 : DFS

1. DFS를 시작해 상하좌우로 연결된 석유를 하나의 덩어리로 탐색한다.
   - 방문 배열을 사용해 같은 석유 칸을 중복 탐색하지 않는다.
2. 각 석유 칸이 위치한 열 번호를 `columns` 집합에 저장한다.
   - `set`을 사용해 하나의 석유 덩어리가 동일한 열에 여러 칸 존재하더라도 열 번호는 한 번만 저장한다.
3. 하나의 석유 덩어리 탐색이 끝나면 해당 덩어리가 차지하는 모든 열에 `size`를 더한다.
   - 열마다 DFS를 다시 실행하지 않고 이미 계산한 덩어리 정보를 재사용한다.


- 시간복잡도 : `O(N × M)` — 각 좌표를 최대 한 번 탐색하며, 덩어리별 열 집합을 처리하는 총비용도 격자 크기에 비례한다.
- 공간복잡도 : `O(N × M)` — 방문 배열, DFS 스택 및 열 정보 저장에 필요한 공간

### 회고

- **몇 번 만에 성공했는지** : 1회

- **잘한 점**
  - 석유 덩어리의 크기를 계산하는 과정과 열별 석유량을 누적하는 과정을 구분해 해결했다. 즉, 탐색 결과를 재사용하는 최적화 방식을 학습했다.
  -set으로 중복 열을 제거하며, 리스트로 열별 누적 결과를 관리하는 구조를 만들었다.

- **개선할 점**
  - DFS를 구현하기 전에 탐색 과정에서 수집해야 하는 정보가 무엇인지 먼저 정의하는 연습이 필요하다.
  - 효율성 테스트가 있는 문제에서는 동일한 영역을 반복 탐색하는 구조가 없는지 확인해야 한다.

- **새로 배운 점**
  - 반복 DFS는 재귀 깊이 제한을 피하면서 큰 2차원 지도도 탐색할 수 있다.

- **느낀 점**
  - 데이터의 중복 처리 여부와 시간복잡도를 고려해 알고리즘을 설계하는 능력을 길러야 한다.
