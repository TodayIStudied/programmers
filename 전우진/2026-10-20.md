# 2026-10-20 | 타겟 넘버

## 문제 설명

- 문제: [프로그래머스 타겟 넘버](https://school.programmers.co.kr/learn/courses/30/lessons/43165)
- 언어: Java
- 모든 숫자에 `+` 또는 `-`를 붙여 `target`을 만드는 방법의 수 구하기

## 접근 방식: DFS

- 각 숫자마다 두 가지 선택이 있으므로 모든 부호 조합을 탐색하는 DFS로 접근함
- `index`: 다음에 사용할 숫자의 위치
- `value`: 지금까지 선택한 부호를 반영한 누적값

**풀이 순서**

```text
count = 0
DFS(index, value):
    if index == 숫자 개수:
        if value == target: count += 1
        return
    DFS(index + 1, value + numbers[index])
    DFS(index + 1, value - numbers[index])
DFS(0, 0)
count 반환
```

- 시간 복잡도: `O(2^n)` — 숫자 n개의 부호 조합을 모두 탐색함
- 공간 복잡도: `O(n)` — 재귀 호출 스택의 최대 깊이

## 회고

- 재귀 상태와 종료 조건을 연결해서 정리했음. 모든 숫자를 사용한 시점에 목표값과 비교함
- 반복 호출에도 결과가 누적되지 않도록 시작할 때 `count`를 0으로 초기화하도록 보완함

# 지게차와 크레인

## 문제 설명

- 문제: [프로그래머스 지게차와 크레인](https://school.programmers.co.kr/learn/courses/30/lessons/388353)
- 언어: Java
- 요청 순서대로 컨테이너를 꺼낸 뒤 창고에 남은 개수 구하기

## 접근 방식: BFS + 시뮬레이션

- 지게차는 요청 시작 시점에 외부에서 접근 가능한 대상만 제거하므로 외부의 빈 공간을 BFS로 탐색함
- `map`을 `(R+2) × (C+2)` 크기로 만들고 `'-'`로 채워 외부 공간을 표현함
- 원본 `storage[r-1]`을 패딩된 배열의 1행·1열부터 저장함

**풀이 순서**

1. 길이 1 요청은 `visited`를 새로 만들고 `(0, 0)`부터 `ArrayDeque`로 BFS 시작함
2. 상하좌우를 확인하고 배열 범위를 벗어나거나 이미 방문한 칸은 제외함
3. 빈칸은 큐에 넣어 탐색하고, 대상 컨테이너는 방문 처리 후 `'-'`로 바꾸고 제거수를 늘림
4. 이번 요청에서 제거한 칸은 큐에서 바로 빼서 그 칸을 통해 탐색을 이어가지 않음
5. 길이 2 요청은 크레인으로 배열 전체에서 대상 컨테이너를 모두 제거함
6. 모든 요청을 처리한 뒤 `R*C - 제거수`를 반환함

- 시간 복잡도: `O(Q*R*C)` — 요청 Q개마다 최대 배열 전체를 탐색함
- 공간 복잡도: `O(R*C)` — 패딩 배열, 방문 배열, BFS 큐 사용함

## 회고

- 외곽을 빈칸으로 패딩해 외부 접근 여부를 `(0, 0)` BFS로 판단하도록 정리했음
- 패딩 좌표와 원본 좌표, 배열 경계를 구분해서 확인할 필요가 있었음. 인덱스와 경계를 수정한 뒤 통과했음
