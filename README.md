0. programmers 백준 허브에 등록해 개인 레포에 연동해두기 
1. 매일 programmers에서 한 문제 풀이하고 개인 레포에 풀이 기록 업로드된 것 확인하기 
2. TodayIStudied organization의 programmers 레포에 각자 브랜치로 공부한 내용(알고리즘 문제) md 파일로 만들어서 push하기
   - 개인 id로 생성된 브랜치만 사용하기 (ex.thisischeese가 id면 thisischeese 브랜치 사용)
   - 공부한 내용은 [TEMPLATE.md](Template.md) 파일 형식 사용하되 필요 시 변형 가능
