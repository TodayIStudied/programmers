- 왜 이 방식으로 풀었나?
```
def solution(dots):
    (x1, y1), (x2, y2), (x3, y3), (x4, y4) = dots
    res1 = (x1 - x2) / (y1 - y2) == (x3 - x4) / (y3 - y4)
    res2 = (x1 - x3) / (y1 - y3) == (x2 - x4) / (y2 - y4)
    res3 = (x1 - x4) / (y1 - y4) == (x2 - x3) / (y2 - y3)
    return 1 if res1 or res2 or res3 else 0
```
