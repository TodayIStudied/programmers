# 프로그래머스 Lv.2 — 미로 탈출

### 문제 설명
- 풀이 URL : [미로 탈출](https://github.com/sunoo2468/codingTestPre/blob/main/Python/%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%98%EB%A8%B8%EC%8A%A4/2/159993.%E2%80%85%EB%AF%B8%EB%A1%9C%E2%80%85%ED%83%88%EC%B6%9C/%EB%AF%B8%EB%A1%9C%E2%80%85%ED%83%88%EC%B6%9C.py)
- 난이도 : Lv.2
- 알고리즘 : BFS
- 학습 목표 : 복집한 탐색 조건을 각각의 최단 경로 문제로 분리하여 해결하기

### 접근 방식 : BFS

1. 미로를 순회하면서 시작점(S), 레버(L), 출구(E)의 좌표를 저장한다.
2. BFS 함수를 정의하여 두 지점 사이의 최단 거리를 계산한다.
3. 시작점에서 레버까지의 최단 거리를 구한다.
4. 레버에서 출구까지의 최단 거리를 구한다.
5. 두 경로 중 하나라도 이동할 수 없다면 -1을 반환한다.
6. 두 경로의 이동 시간을 합산하여 반환한다.

- 시간복잡도 : `O(N × M)`
- 공간복잡도 : `O(N × M)`

### 회고

- **몇 번 만에 성공했는지** : 3회 (이전의 해결한 코드들을 참고하며)
- **잘한 점** : 복합적인 요구사항을 독립적인 탐색 문제로 분리하고, BFS를 함수로 모듈화하여 중복 코드를 줄이는 방법을 학습했다.
- **개선할 점** : 탐색 조건이 여러 개 주어졌을 때 모든 상태를 한 번에 관리하기보다 문제를 분리할 수 있는지 먼저 판단하는 연습이 필요하다.
- **새로 배운 점** : 동일한 BFS 함수를 서로 다른 시작점과 목적지에 재사용할 수 있으며, 탐색마다 방문 배열을 독립적으로 초기화해야 한다.
- **느낀 점** : 이전의 풀던 단순한 최단 거리 문제와 다르게, 반드시 거쳐야 하는 지점이 있다는 차이가 있었다. 복잡한 조건도 작은 문제로 분리하면 기존에 학습한 알고리즘으로 해결할 수 있다는 점을 배웠다.
