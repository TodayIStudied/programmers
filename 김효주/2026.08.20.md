
## 문제 설명
하샤드수, x만큼 간격이 있는 n개 숫자, 나머지 1되는 수

모두 반복문 사용이다. 

## 한줄 반복문
```
def Harshad(n):
    return n%sum(int(x) for x in str(n)) == 0
```

나의 경우, 한 문장으로 줄여쓰는 방법에 익숙치 않아 이 문장을 따로 작성했는데,
익숙해지려고 노력해야 할 것 같다는 생각이 든다.
특히 반복문의 한줄쓰기...

## 회고
조건문의 경우, 
- x>0
- x<0
- x=0
모두고려하여야 하는데, 자꾸 빼먹는 실수를 고쳐야 할 것 같다.
