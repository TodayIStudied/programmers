### 접근 방식 : 1. 완전탐색 - 2중 루프 필터링
- 인센티브 제외 대상을 거르는 배열 필터링과 석차 계산 로직을 분리하여 구현했다.
- N이 최대 100,000인데 2중 루프(O(N^2))로 순회하여 테스트 케이스(22번 등)에서 시간 초과가 발생했다.
- 조건이 추가될 때마다 예외 처리를 덧대다 보니 코드가 근시안적이고 지나치게 복잡해졌다.

### 접근 방식 : 2. 정렬과 그리디 (O(N log N) 최적화)
- 근무 태도 점수 내림차순, 동료 평가 점수 오름차순으로 다중 정렬 조건을 설정했다.
- 순회하면서 동료 평가 점수의 최댓값(`max_b`)만 갱신하는 그리디 방식으로 로직을 개선했다.
- 첫 점수가 같을 때 오름차순 정렬을 해둔 덕분에, 별도의 복잡한 if문 예외 처리 없이 억울하게 탈락하는 경우를 완벽하게 방지할 수 있었다.
- 다중 정렬 그리디 방식은 처음 보는 거라 배웠다 나중에 떠올려야함

### 회고
- 몇 번만에 성공했는지 : 실패
- 잘한 점 : 코드가 복잡해졌음을 인지하고 고치려고 시도함
- 개선할 점 : 그리디 방식에 대한 알고리즘 적용 방식을 빠르게 떠올려야함
