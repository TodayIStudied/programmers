### 접근 방식 : 1. DFS 
- 왜 이 방식으로 풀었나?
  - 5자리 밖에 안되기 때문에 다 탐색해도 번호 알 수 있음
  - 시간초과 걱정 x
  - dfs로 타겟 문자열 만날 때까지만 돌면 됨
```python
  def solution(word):
      words = []
  
      def dfs(s):
          if len(s) == 5:
              return
          for c in "AEIOU":
              words.append(s + c)
              dfs(s + c)
  
      dfs("")
      return words.index(word) + 1
```
