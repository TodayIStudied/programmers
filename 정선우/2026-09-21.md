### 접근 방식 : 완전탐색 + 순열
- 처음 주어진 순서대로 던전을 탐험하는 코드를 작성했다.
- 버블 정렬을 생각했지만, 하나의 순서로 정렬하는 것이 아니라 **가능한 모든 순서를 확인해야 하므로 순열**을 사용했다.

### 회고
- 몇 번만에 성공했는지 : 2회
- 잘한 점 :
  - 처음부터 던전을 탐험하는 기본 로직은 바로 구현했다.
  - 주어진 순서대로만 확인하면 안 되고 **순서를 바꿔가며 반복해야 한다**는 점까지 스스로 생각했다.

- 새로 배운 점 :
  - `permutations()`를 이용하여 순열 사용 가능하다.
  - 다른 사람의 풀이를 보면서 같은 완전탐색을 **DFS + 백트래킹**으로도 구현할 수 있다는 것을 알게 되었다.

```python
visited[j] = 1   # 선택
dfs(...)         # 탐색
visited[j] = 0   # 원상복구
```

  - 백트래킹은 **선택 → 탐색 → 원상복구 → 다른 선택**을 반복하는 방식이다.

- 느낀 점 :
  - 순서를 전부 바꿔봐야 한다는 생각은 했지만, 이를 직접 구현하지 않고 `permutations()`로 간단하게 처리할 수 있다는 점이 인상적이었다.
  - 이번 문제는 풀이 자체보다 **순열과 추가적으로 DFS + 백트래킹이라는 새로운 방법을 알게 되었다.**
