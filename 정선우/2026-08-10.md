# 같은 숫자는 싫어

## 문제 정보

* 플랫폼: Programmers
* 난이도: Level 1
* 문제 번호: 12906
* 사용 언어: Java
* 분류: 배열, ArrayList

## 문제 요약

정수 배열 `arr`에서 연속으로 나타나는 같은 숫자를 하나만 남기고 제거한 배열을 반환한다.

예를 들어 다음과 같은 배열이 주어진다면,

```text
[1, 1, 3, 3, 0, 1, 1]
```

결과는 다음과 같다.

```text
[1, 3, 0, 1]
```

중요한 점은 모든 중복을 제거하는 것이 아니라 **연속된 중복만 제거**한다는 것이다.

따라서 마지막에 다시 등장한 `1`은 제거하면 안 된다.

---

## 문제 접근

처음에는 현재 숫자와 바로 이전 숫자를 비교하면 된다고 생각했다.

```java
arr[i] == arr[i - 1]
```

두 값이 같다면 연속된 중복이므로 결과에 추가하지 않고, 다르다면 결과에 추가하면 된다.

```text
현재 값 == 이전 값
→ 추가하지 않음

현재 값 != 이전 값
→ 결과에 추가
```

하지만 일반 배열은 생성할 때 크기를 지정해야 한다.

```java
int[] answer = new int[크기];
```

이 문제에서는 연속된 중복이 몇 개 제거될지 모르기 때문에 결과 배열의 크기를 처음부터 결정하기 불편하다.

따라서 크기를 동적으로 관리할 수 있는 `ArrayList`에 먼저 결과를 저장한 뒤 마지막에 `int[]`로 변환했다.

---

## 풀이 코드

```java
import java.util.*;

public class Solution {
    public int[] solution(int[] arr) {

        ArrayList<Integer> list = new ArrayList<>();

        list.add(arr[0]);

        for (int i = 1; i < arr.length; i++) {
            if (arr[i] != arr[i - 1]) {
                list.add(arr[i]);
            }
        }

        int[] answer = new int[list.size()];

        for (int i = 0; i < list.size(); i++) {
            answer[i] = list.get(i);
        }

        return answer;
    }
}
```

---

## 코드 설명

### 첫 번째 값 저장

```java
list.add(arr[0]);
```

첫 번째 숫자는 앞에 비교할 숫자가 없으므로 무조건 결과에 추가한다.

그 이후부터 이전 값과 비교하기 위해 반복문을 `1`부터 시작한다.

```java
for (int i = 1; i < arr.length; i++)
```

---

### 연속된 값 비교

```java
if (arr[i] != arr[i - 1]) {
    list.add(arr[i]);
}
```

현재 값과 바로 이전 값이 다른 경우에만 결과에 추가한다.

예를 들어

```text
[1, 1, 3, 3, 0, 1, 1]
```

을 순회하면

```text
1 → 첫 번째 값이므로 추가

1 → 이전 1과 같음 → X

3 → 이전 1과 다름 → 추가

3 → 이전 3과 같음 → X

0 → 이전 3과 다름 → 추가

1 → 이전 0과 다름 → 추가

1 → 이전 1과 같음 → X
```

따라서

```text
[1, 3, 0, 1]
```

이 남는다.

# 새롭게 배운 내용

## 1. ArrayList

`ArrayList`는 **배열을 내부적으로 사용하는 List 자료구조**이다.

일반 배열은 생성할 때 크기를 정해야 한다.

```java
int[] arr = new int[3];
```

따라서 크기가 고정된다.

반면 `ArrayList`는

```java
ArrayList<Integer> list = new ArrayList<>();
```

처럼 만들고 필요한 만큼 값을 추가할 수 있다.

```java
list.add(10);
list.add(20);
list.add(30);
```

결과:

```text
[10, 20, 30]
```

필요한 공간이 부족하면 내부적으로 더 큰 배열을 확보하기 때문에 사용하는 입장에서는 크기를 직접 관리할 필요가 없다.

따라서

```text
Array
→ 크기가 고정된 배열

ArrayList
→ 내부적으로 배열을 사용하지만 크기를 동적으로 관리해주는 List
```

라고 이해했다.

---

## 2. ArrayList의 기본 사용법

### 생성

```java
ArrayList<Integer> list = new ArrayList<>();
```

### 값 추가

```java
list.add(10);
```

### 값 가져오기

```java
list.get(0);
```

### 값 수정

```java
list.set(0, 20);
```

### 원소 개수

```java
list.size();
```

---

## 3. 배열과 ArrayList의 차이

| 구분    | 배열               | ArrayList            |
| ----- | ---------------- | -------------------- |
| 예시    | `int[]`          | `ArrayList<Integer>` |
| 크기    | 고정               | 동적                   |
| 값 추가  | 직접 인덱스 지정        | `add()`              |
| 값 접근  | `arr[i]`         | `list.get(i)`        |
| 값 수정  | `arr[i] = value` | `list.set(i, value)` |
| 원소 개수 | `arr.length`     | `list.size()`        |

특히 다음 두 표현을 헷갈리지 않도록 한다.

```java
arr.length
```

배열의 길이를 가져온다.

```java
list.size()
```

List에 들어있는 원소의 개수를 가져온다.

---

## 4. List와 ArrayList

`List`는 리스트 자료구조가 가져야 할 기능을 정의한 인터페이스이고, `ArrayList`는 이를 실제로 구현한 클래스 중 하나이다.

```java
List<Integer> list = new ArrayList<>();
```

이 경우 실제 생성되는 객체는 `ArrayList`이다.

```text
List
 ├─ ArrayList
 └─ LinkedList
```

이번 문제에서는 실제 자료구조로 `ArrayList`를 사용했다.

---

## 5. 일반 for문과 for-each

값만 하나씩 확인한다면 다음처럼 for-each를 사용할 수 있다.

```java
for (int num : arr) {
}
```

하지만 이번 문제에서는

```java
arr[i]
arr[i - 1]
```

처럼 현재 위치와 이전 위치를 비교해야 한다.

따라서 인덱스 `i`가 필요한 일반 `for`문을 사용하는 것이 편하다.

```java
for (int i = 1; i < arr.length; i++) {
}
```

단순 배열 순회에서는 일반 `for`문과 for-each 모두 시간복잡도가 `O(N)`이므로 성능보다는 **인덱스가 필요한지 여부**에 따라 선택하면 된다.

---

## 6. ArrayList를 int[]로 변환

문제에서 요구하는 반환 타입은

```java
public int[] solution(int[] arr)
```

이므로 최종적으로 `int[]`를 반환해야 한다.

하지만 중간 결과는 `ArrayList<Integer>`에 저장했다.

따라서 먼저 List의 크기만큼 배열을 생성한다.

```java
int[] answer = new int[list.size()];
```

그리고 값을 하나씩 옮긴다.

```java
for (int i = 0; i < list.size(); i++) {
    answer[i] = list.get(i);
}
```

즉,

```text
ArrayList<Integer>
[1, 3, 0, 1]

        ↓

int[]
[1, 3, 0, 1]
```

로 변환하는 과정이다.

---

## 시간 복잡도

입력 배열을 한 번 순회한다.

```text
O(N)
```

마지막에 `ArrayList`를 `int[]`로 변환하면서 다시 한 번 순회한다.

```text
O(N)
```

따라서 전체 시간 복잡도는

```text
O(N)
```

이다.

---

## 공간 복잡도

결과를 저장하기 위한 `ArrayList`와 최종 배열을 사용한다.

최악의 경우 입력 배열에 연속된 중복이 하나도 없다면 모든 값을 저장해야 하므로 추가 공간은

```text
O(N)
```

이다.

## 배운 점

처음에는 현재 숫자와 이전 숫자를 비교해야 한다는 것까지 생각했지만, 결과를 어떻게 저장해야 하는지에서 막혔다.

이번 문제를 통해 일반 배열은 크기가 고정되어 있기 때문에 결과의 크기를 미리 알기 어려운 상황에서는 `ArrayList`와 같은 동적 자료구조를 사용할 수 있다는 것을 배웠다.

또한 배열과 ArrayList의 접근 방식이 다르다는 것도 알게 되었다.

```text
배열
arr[i]
arr.length

ArrayList
list.get(i)
list.size()
```

그리고 문제를 풀 때 단순히 중복이라는 단어만 보고 `HashSet`을 사용하는 것이 아니라,

```text
모든 중복 제거 → HashSet 등을 고려

연속된 중복 제거 → 이전 값과 비교
```

처럼 **문제에서 정확히 어떤 중복을 처리하라고 하는지 구분해야 한다**는 것을 배웠다.
