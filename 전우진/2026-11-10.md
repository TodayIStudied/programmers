### 문제 설명

- 문제 URL : [연속 부분 수열 합의 개수](https://school.programmers.co.kr/learn/courses/30/lessons/131701)
- 풀이일 : 2026-11-10
- 원형 수열에서 만들 수 있는 연속 부분 수열의 합 중 서로 다른 값의 개수를 구하는 문제.

### 접근 방식 : 누적 합과 집합

처음에는 길이와 시작 위치를 정하고, 해당 구간의 원소를 다시 더했다. 길이가 늘어날 때마다 앞부분도 처음부터 계산해서 중복 작업이 많았다.

- 시작점을 하나씩 정하고, 시작점이 바뀔 때 합을 0으로 초기화한다.
- 길이를 1부터 N까지 늘리면서 이전 합에 다음 원소 하나만 더한다.
- 배열에 접근할 때 `(start + count) % N`을 사용해 끝을 지나면 처음으로 돌아간다.
- 구한 합을 집합에 넣어 중복을 제거하고, 마지막에 집합의 크기를 반환한다.

같은 시작점에서 구한 합을 재사용하는 게 포인트다. 예를 들어 7, 9, 1을 차례로 더하면 7 → 16 → 17이 된다. 구간이 늘어날 때 처음부터 더할 필요가 없다.

### 복잡도

- N은 수열의 길이.
- 시간 : 평균 O(N²). 시작점 N개에서 각각 N번 더한다. 해시 삽입은 평균 O(1)로 본다. 구간마다 다시 더하던 O(N³) 방식보다 줄어든다.
- 공간 : O(N²). 집합에 서로 다른 합이 최대 O(N²)개 저장될 수 있다.

### 회고

처음에는 시작 위치 대신 길이 변수로 배열에 접근해서 인덱스가 잘못됐다. 원형 처리를 위해 반복 변수 자체를 줄인 것도 종료 조건에 영향을 줬다. 반복 변수는 그대로 두고, 배열에 접근할 때만 나머지 연산을 적용하도록 고쳤다.

수정하면서 시작 원소를 미리 넣고 반복문에서도 다시 더하는 실수도 했다. 합을 0으로 시작하면 각 원소를 한 번씩 더할 수 있다. 같은 시작점의 이전 합을 버리지 않고 다음 원소만 추가하는 방식으로 바꿔 채점까지 통과했다.
