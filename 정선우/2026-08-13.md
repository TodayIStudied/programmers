# 의상

## 문제 정보

- 플랫폼: Programmers
- 난이도: Level 2
- 문제 번호: 42578
- 사용 언어: Java
- 분류: HashMap, 경우의 수

## 풀이 코드

```java
import java.util.*;

class Solution {
    public int solution(String[][] clothes) {

        HashMap<String, Integer> map = new HashMap<>();

        // 옷 종류별 개수 계산
        for (int i = 0; i < clothes.length; i++) {
            String type = clothes[i][1];

            map.put(type, map.getOrDefault(type, 0) + 1);
        }

        // 경우의 수를 곱하므로 1부터 시작
        int answer = 1;

        // 종류별 옷 개수를 하나씩 확인
        for (int count : map.values()) {

            // 해당 종류를 입지 않는 경우까지 포함
            answer *= (count + 1);
        }

        // 아무것도 입지 않는 경우 제외
        return answer - 1;
    }
}
```

## 오늘 배운 내용

### 1. 2차원 배열 접근

이번 문제에서는 `String[][]` 형태의 2차원 배열을 사용했다.

```java
clothes[i][0] // 옷 이름
clothes[i][1] // 옷 종류
```

2차원 배열은 `[행][열]` 형태로 원하는 값에 접근할 수 있다.

예를 들어

```java
String type = clothes[i][1];
```

을 사용하면 현재 옷의 종류를 가져올 수 있다.

### 2. HashMap으로 개수 세기

```java
map.put(type, map.getOrDefault(type, 0) + 1);
```

`getOrDefault()`를 사용하면 해당 Key가 존재할 경우 기존 값을 가져오고, 존재하지 않을 경우 기본값을 사용할 수 있다.

따라서 같은 종류의 옷이 몇 개 존재하는지 쉽게 계산할 수 있다.

```text
headgear → 2
eyewear  → 1
```

### 3. HashMap의 Value만 순회하기

```java
for (int count : map.values()) {
}
```

`map.values()`를 사용하면 HashMap에 저장된 Value만 가져와 순회할 수 있다.

이번 문제에서는 옷 종류의 이름보다 각 종류의 **개수**가 필요했기 때문에 `values()`를 사용했다.

### 4. 경우의 수 계산

각 종류의 옷에서는 해당 종류를 아예 착용하지 않는 경우도 선택할 수 있다.

따라서 종류별 선택지는

```text
옷 개수 + 1
```

이 된다.

예를 들어

```text
headgear = 2개
eyewear  = 1개
```

라면

```text
headgear → 2 + 1 = 3가지
eyewear  → 1 + 1 = 2가지

3 × 2 = 6가지
```

가 된다.

하지만 여기에는 모든 종류의 옷을 하나도 입지 않는 경우가 포함되어 있다.

따라서 마지막에

```java
return answer - 1;
```

을 사용해 아무것도 입지 않는 경우 1가지를 제외한다.

## 핵심 정리

- `clothes[i][1]`을 이용해 2차원 배열에서 옷 종류를 가져올 수 있다.
- `HashMap`을 이용해 종류별 등장 횟수를 저장할 수 있다.
- `getOrDefault()`는 빈도를 계산할 때 유용하다.
- `map.values()`를 사용하면 HashMap의 Value만 순회할 수 있다.
- 경우의 수를 곱할 때는 `answer = 1`부터 시작한다.
- 선택하지 않는 경우가 존재하면 `개수 + 1`로 계산한다.
- 마지막에 아무것도 선택하지 않는 경우 1가지를 제외한다.
