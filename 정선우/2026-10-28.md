- 난이도 : Lv.2
- 알고리즘 : 그리디(Greedy)

### 접근 방식 : 정렬 + 그리디

1. 끝점이 가장 빠른 미사일부터 처리하고, 해당 끝점 직전에서 요격하는 전략을 사용한다.
2. 끝점이 작은 구간부터 정렬한다. 이때, 첫 번째 미사일을 요격했다고 가정한다
3. 시작점이 이전 미사일의 끝점보다 크거나 같다면 새로운 요격이 필요하다. 현재 구간의 끝점으로 갱신하고 새로운 요격을 진행한다.

- 시간복잡도 : `O(N log N)` — 끝점 기준 정렬
- 공간복잡도 : `O(N)` — 정렬 과정에서 추가 메모리가 사용될 수 있음

### 회고

- **몇 번 만에 성공했는지** : 1회
- **잘한 점**
  - 문제의 핵심을 파악하고 해결 전략을 설계했다. 하나의 요격으로 여러 구간을 처리할 수 있다는 점에 주목해 최소 요격 횟수를 구하는 방향으로 접근했다.
  - 상태를 최소화해 문제를 해결했다. 모든 요격 위치나 격추 여부를 별도로 저장하지 않고, last_end와 answer만 갱신하는 방식으로 해결 로직을 단순화했다.

- **개선할 점**
  - 구간의 경계가 포함되는지 확인해 `<`와 `<=`, `>`와 `>=` 조건을 정확하게 구분해야 한다.
  - `sort(key=lambda x: x[1])`처럼 2차원 리스트를 특정 원소 기준으로 정렬하는 Python 문법을 익혀야 한다.

- **새로 배운 점**
  - `targets[1:]`을 이용하면 첫 번째 원소를 초기 처리한 뒤 나머지 원소만 순회할 수 있다.

- **느낀 점**
  - 그리디 문제를 연속해서 연습하면서, 문제의 조건을 분석하고 최소 횟수를 구하기 위한 전략을 스스로 생각하는 데 점차 익숙해졌다.
  - 이번에는 요격 위치를 정하고 이미 격추된 구간을 제외하는 핵심 아이디어를 직접 도출할 수 있었다.
  - 다만 정렬 기준과 Python 구현은 아직 부족하다 생각하므로, 다음부터는 DFS의 재귀 호출과 방문 처리, 백트래킹을 집중적으로 연습할 계획이다.
