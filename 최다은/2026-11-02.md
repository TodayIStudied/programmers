### 접근 방식 : 1. DP
- 왜 이 방식으로 풀었나?
  - 가장 직관적으로 떠오르는 건 백트래킹으로 완탐
  - 그런데 열 4개고 행은 최대 100,000라서 최대 3**100,000 번 탐색해야 할 수 있음 <- 같은 열 탐색 불가니까 
  - 따라서 1차원 DP로 풀이
  - 이동하는 방향이 정해져있고 그리디하게 풀 수도 없으니까
  - i행 j열까지의 최대 이동 점수를 업데이트하면 됨
  - 점화식 : dp[i][j] = land[i][j] + 방문 가능한 dp[i-1][:] 중 max 
- 시간복잡도, 공간복잡도 관점에서의 성능 비교
  - 메모리: 21.7 MB, 시간: 171.95 ms
