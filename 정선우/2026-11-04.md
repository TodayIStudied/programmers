# 프로그래머스 Lv.2 — 혼자 놀기의 달인

- 난이도 : Lv.2
- 알고리즘 : DFS, 그래프 탐색, 사이클 탐색

### 접근 방식 : DFS + 방문 처리

1. 상자에 적힌 번호를 따라가며 연결된 상자들을 하나의 그룹으로 묶는다.
   - 상자 번호는 1부터 시작하지만 리스트 인덱스는 0부터 시작하므로 `cards[current] - 1`로 다음 위치를 계산한다.
2. DFS로 그룹 크기를 비교하며, 상자 탐색을 진행한다.
3. 해당 그룹의 크기를 `groups` 리스트에 저장한다.
   - 모든 상자가 방문 처리될 때까지 반복한다.
4. 그룹 크기를 내림차순으로 정렬한다.
   - 그룹이 하나뿐이라면 `0`을 반환한다.
   - 그룹이 두 개 이상이라면 가장 큰 두 그룹의 크기를 곱한다.

- 시간복잡도 : `O(N + K log K)` — 모든 상자를 한 번씩 탐색하고 그룹 크기를 정렬한다. (`K`는 그룹 개수)
- 공간복잡도 : `O(N)` — 방문 배열과 그룹 크기 리스트를 사용한다.

### 회고

- **몇 번 만에 성공했는지** : 1회
- **잘한 점**
  - **문제를 그래프 구조로 해석했다.** 각 상자에 적힌 번호를 다음 노드로 연결되는 관계로 보고, 연결된 상자들을 하나의 그룹으로 처리하는 방식으로 접근했다.

- **개선할 점**
  - 상자 번호와 리스트 인덱스의 차이를 명확히 구분해 인덱스 오류를 방지해야 한다.
  - DFS를 단순히 재귀 호출로만 이해하지 않고, 반복문을 이용한 연결 관계 탐색에도 적용할 수 있도록 연습해야 한다.

- **새로 배운 점**
  - 각 노드가 다음 노드 하나를 가리키는 구조에서는 반복문으로 연결 관계를 따라가며 탐색할 수 있다.

- **느낀 점**
  - 지난번 무인도 여행에서는 2차원 지도에서 상하좌우로 연결된 영역을 탐색했다면, 이번에는 1차원 배열에서 상자 번호를 따라가는 방식으로 DFS를 학습했다.
  - 같은 DFS라도 데이터의 연결 구조에 따라 탐색 방식이 달라질 수 있다는 점을 이해했다.
