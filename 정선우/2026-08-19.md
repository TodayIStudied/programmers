# 문자열 내 마음대로 정렬하기

## 풀이 코드

```java
import java.util.Arrays;

class Solution {
    public String[] solution(String[] strings, int n) {

        Arrays.sort(strings, (a, b) -> {
            char charA = a.charAt(n);
            char charB = b.charAt(n);

            // n번째 문자가 같으면 문자열 전체를 사전순으로 비교
            if (charA == charB) {
                return a.compareTo(b);
            }

            // n번째 문자 기준 오름차순 정렬
            return charA - charB;
        });

        return strings;
    }
}
```

---

## 오늘 배운 것

### 1. `charAt()`으로 특정 위치 문자 가져오기

```java
String word = "sun";

word.charAt(1); // 'u'
```

문자열의 특정 위치를 기준으로 비교할 때 사용할 수 있다.

---

### 2. Comparator 복습

```java
Arrays.sort(strings, (a, b) -> {
    ...
});
```

- `Arrays.sort()` → 전체 정렬
- Comparator → `a`, `b` 중 어떤 값이 앞에 올지 판단

---

### 3. char끼리 비교하기

```java
return charA - charB;
```

결과가

```text
음수 → a가 앞
0    → 같음
양수 → b가 앞
```

이 되므로 문자 오름차순 정렬에 사용할 수 있다.

---

### 4. 정렬 기준이 여러 개인 경우

오늘 가장 중요하게 배운 부분.

```java
if (charA == charB) {
    return a.compareTo(b);
}

return charA - charB;
```

정렬 기준을 순서대로 적용할 수 있다.

```text
1순위 → n번째 문자
          ↓ 같으면
2순위 → 문자열 전체 사전순
```

즉 Comparator에서는 **1차 조건이 같을 때 2차 정렬 조건을 적용하는 방식**도 만들 수 있다.

---

## 핵심 정리

```text
charAt(n)
→ 문자열의 n번째 문자 가져오기

charA - charB
→ 문자 오름차순 비교

a.compareTo(b)
→ 문자열 전체 사전순 비교

Comparator
→ 하나의 기준뿐 아니라 여러 정렬 기준도 만들 수 있다.
```
