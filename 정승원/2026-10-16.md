## 좌우로 움직이는 로봇

### 문제 설명

- 문제명: 좌우로 움직이는 로봇
- 문제 URL: [좌우로 움직이는 로봇](https://www.codetree.ai/trails/complete/curated-cards/challenge-robot-moving-from-side-to-side)
- 풀이 URL: [내 풀이 코드](https://github.com/HappyPotatohappy/CodingTest/blob/895d2dc494e0bedf2d6d97136c97e34baa3ef3e1/trail2/좌우로%20움직이는%20로봇/robot-moving-from-side-to-side.py)
- 사용 언어: Python
- 분류: Trail 2 / 시뮬레이션 II / 배열 기록 (난이도: 보통)
- 로봇 A와 B가 수직선의 0에서 동시에 출발한다.
- A는 n개, B는 m개의 명령 `(t, d)`를 차례대로 수행한다. 각 명령은 `d` 방향(`L` 또는 `R`)으로 1초에 1칸씩 `t`초 동안 움직이는 것이다.
- 명령을 모두 마친 로봇은 그 자리에 멈춰 있다.
- 1초 전에는 서로 다른 위치에 있다가 이번에 같은 위치에 오게 되는 경우를 "만남"으로 세고, 그 횟수를 출력한다.

### 접근 방식 : 1. 시간별 위치를 배열에 기록한 뒤 비교

- 왜 이 방식으로 풀었나?
  - 두 로봇의 명령은 따로 주어지고 명령마다 걸리는 시간이 달라서, 명령 단위로 바로 비교하기 어렵다.
  - 대신 **"t초에 어디 있는가"**를 배열 `vt_a[t]`, `vt_b[t]`에 1초 단위로 기록하면, 두 로봇의 움직임이 같은 시간축 위에 놓인다.
  - 그러면 만남 판정은 같은 인덱스의 두 값만 비교하는 문제가 된다.

- 위치를 기록하는 방법
  - `now_a`는 지금까지 A가 움직인 총 시간이다.
  - 명령 `(time, direction)`마다 `now_a + 1`부터 `now_a + time`까지 `vt_a[i] = vt_a[i - 1] + di`로 1칸씩 기록하고 `now_a += time`한다.
  - 명령이 끝난 뒤의 칸은 모두 마지막 위치 `vt_a[now_a]`로 채운다. 멈춰 있는 로봇에게 다른 로봇이 와서 만나는 경우가 있기 때문이다.
  - B도 같은 방식으로 `vt_b`를 채운다.

- 만남을 세는 방법
  - `t`를 1부터 순회하며 `vt_a[t - 1] != vt_b[t - 1]`이고 `vt_a[t] == vt_b[t]`이면 `cnt += 1`한다.
  - 두 로봇이 같은 위치에서 같은 방향으로 함께 움직이는 동안은 직전에도 같은 위치였으므로 세지 않는다.
  - 0초에는 둘 다 0에 있지만 직전 시간이 없으므로 만남으로 세지 않는다.

- 구현에서 주의할 점
  - 배열 크기 `mxNum = 2000000`은 두 로봇의 전체 이동 시간보다 커야 한다.
  - 명령이 끝난 뒤를 마지막 위치로 채우지 않으면 0으로 남아서, 실제로는 만나지 않았는데 0에서 만난 것으로 셀 수 있다.

- 시간복잡도, 공간복잡도 관점에서의 성능 비교
  - 시간복잡도: **O(MAX)** (MAX = 배열 크기 2,000,000)
    - 위치 기록과 남은 칸 채우기, 만남 비교가 모두 배열 끝까지 돈다. 입력이 작아도 항상 MAX번 반복한다.
    - 배열을 실제 최대 이동 시간 T에 맞추면 **O(T)**가 된다.
  - 공간복잡도: **O(MAX)**
    - 길이 MAX인 배열 2개를 쓴다. 제출 결과 메모리는 47MB였다.

### 회고

- 몇 번만에 성공했는지: 1번
- 잘한 점:
  - 두 로봇의 위치를 1초 단위 배열로 펼쳐서, 명령 길이가 서로 달라도 같은 시간축에서 비교할 수 있게 했다.
  - 명령이 끝난 뒤를 마지막 위치로 채워서 멈춘 로봇과 만나는 경우를 처리했다.
  - "직전에는 다르고 지금은 같다" 조건으로 함께 움직이는 구간을 중복해서 세지 않았다.
  - 방향을 `{"L": -1, "R": 1}` 딕셔너리로 바꿔서 이동 계산을 한 줄로 처리했다.
- 개선할 점 (AI):
  - A와 B를 기록하는 코드가 거의 같으므로 `record(moves)` 같은 함수 하나로 묶으면 중복이 줄어든다.
  - `t`, `d`, `t_b`, `d_b`, `a`, `b` 리스트는 저장만 하고 쓰지 않는다. 특히 `t`는 마지막 반복문의 변수 이름과 겹치니 지우는 게 좋다.
