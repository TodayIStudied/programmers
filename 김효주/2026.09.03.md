### 접근 방식 : 자리수 세기 = len(str(number))

숫자의 자릿수를 구할 때 숫자를 문자열로 변환한 뒤 `len()`을 사용하면 간단하게 자릿수를 셀 수 있다.

### 접근 방식 : 최빈값 구하기 = array.count(i)

`array.count(i)`를 사용하면 배열 안에서 특정 값 `i`가 몇 번 등장하는지 확인할 수 있다.

처음에는 `max_count` 하나만 사용하여 최빈값을 구하려고 했지만, `count()`가 반환하는 값은 **가장 많이 등장한 숫자 자체가 아니라 등장 횟수**라는 점을 놓쳤다.

따라서
- `max_count` : 현재까지 가장 많이 등장한 횟수
- `answer` : 그 횟수를 가진 실제 값

으로 역할을 분리하여 계산해야 함을 알게 되었다.

또한 같은 숫자를 여러 번 검사하면 최빈값이 하나인 경우에도 중복으로 판단할 수 있기 때문에, `set(array)`를 사용해 중복된 값을 제거한 뒤 각 숫자의 등장 횟수를 비교하였다.

### 회고
- 몇 번만에 성공했는지 : 매우 다수
- 잘한 점 : `count()`를 활용해 각 숫자의 등장 횟수를 비교하는 방향까지는 스스로 생각해냈다. 또한 오류가 발생한 뒤 변수 하나에 여러 역할을 넣는 것이 문제라는 점을 이해했다.
- 개선할 점 : 변수에 어떤 값을 저장하고 있는지 명확히 구분해야 한다. 특히 `max_count`처럼 이름이 등장 횟수를 의미하는 변수와 실제 정답 값을 저장하는 변수는 분리해서 생각하는 습관이 필요하다. 또한 반복문에서 같은 값을 여러 번 검사하고 있지는 않은지 확인해야겠다.
