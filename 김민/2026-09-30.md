### 접근 방식 : DP

* 작은 수에서 큰 수로 가는 중복 부분 문제를 해결하기 위해 1차원 DP 배열을 사용했습니다.
* 각 숫자 `i`에 대해 이전 가능한 연산 상태(`i / 2`, `i / 3`, `i - n`)의 최소 연산 횟수를 참조하여 $O(y)$ 시간복잡도로 해결했습니다.

### 회고

* 몇 번만에 성공했는지 : 1번
* 잘한 점 : 이전 상태를 역추적하는 바텀업 점화식을 통해 원트로 해결
* 개선할 점 : $x = y$일 때 반복문을 돌지 않고 즉각 0을 반환하는 조기 종료 조건을 추가하지 않았고, 고정 크기 전역 배열 대신 $y + 1$ 크기로 동적 할당하면 메모리를 더 아낄 수 있음
