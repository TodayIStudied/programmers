## 독서실의 거리두기 4

### 문제 설명

- 문제명: 독서실의 거리두기 4
- 문제 URL: [독서실의 거리두기 4](https://www.codetree.ai/trails/complete/curated-cards/challenge-study-cafe-keeping-distance-4)
- 풀이 URL: [내 풀이 코드](https://github.com/HappyPotatohappy/CodingTest/blob/bed56abab5c5f8dc7263e71fe31918b86d2476a8/trail2/독서실의%20거리두기%204/study-cafe-keeping-distance-4.py)
- 사용 언어: Python
- 일렬로 놓인 n개의 좌석 상태가 주어진다. `1`은 사람이 앉아 있는 자리, `0`은 빈자리다.
- 기존 사람들의 자리는 유지한 채, 서로 다른 빈자리 두 곳에 사람을 한 명씩 추가한다.
- 배치 후 앉아 있는 모든 사람 사이의 거리 중 가장 가까운 두 사람의 거리가 최대가 되도록 하고, 그 값을 출력한다.
- 두 자리 사이의 거리는 인덱스의 차이다. 사이에 있는 빈자리의 개수와는 다르다.

### 접근 방식 : 1. 빈자리 두 곳 선택 + 모든 사람 쌍의 최소 거리 계산을 통한 완전탐색

- 왜 이 방식으로 풀었나?
  - 새로 앉을 두 자리를 정하면, 해당 배치에서 가장 가까운 두 사람의 거리를 계산할 수 있다.
  - 따라서 가능한 빈자리 두 곳을 모두 선택하고, 각 배치의 최소 거리 중 가장 큰 값을 구한다.
  - 핵심은 **각 배치 안에서는 최솟값을 구하고, 배치들 사이에서는 최댓값을 구하는 것**이다.

- 새로 앉을 두 자리를 선택하는 방법
  - 문자열로 입력받은 좌석 상태를 정수 리스트 `seat`로 변환한다.
  - 바깥쪽 두 반복문의 `i`, `j`로 추가할 두 사람의 위치를 선택한다.
  - `seat[i] == 1` 또는 `seat[j] == 1`이면 이미 사람이 있는 자리이므로 건너뛴다.
  - `i == j`인 경우도 제외해 같은 자리에 두 사람을 앉히지 않는다.
  - 유효한 두 자리를 찾으면 `seat[i], seat[j] = 1, 1`로 임시 배치한다.

- 배치의 최소 거리를 계산하는 방법
  - 매 배치마다 `mn = 100`으로 초기화한다.
  - 안쪽 두 반복문의 `k`, `l`로 좌석 쌍을 확인한다. `l`은 `k + 1`부터 순회하므로 항상 `k < l`이다.
  - `seat[k] == 1 and seat[l] == 1`이면 두 사람 사이의 거리 `l - k`를 계산한다.
  - `mn = min(mn, l - k)`로 현재 배치에서 가장 가까운 두 사람의 거리를 갱신한다.
  - 새로 앉은 두 사람뿐 아니라 기존 사람과 새 사람, 기존 사람끼리의 거리도 모두 비교한다.

- 원상 복구와 정답 갱신
  - 거리 계산을 마치면 `seat[i], seat[j] = 0, 0`으로 두 자리를 다시 비운다.
  - 복구하지 않으면 다음 후보를 검사할 때 이전에 추가한 사람이 남아 있어 잘못된 배치를 평가하게 된다.
  - `mx = max(mn, mx)`로 지금까지 확인한 최소 거리 중 가장 큰 값을 저장한다.
  - 모든 후보를 검사한 뒤 `mx`를 출력한다.

- 예시로 확인하기: `n = 10`, `seat = 1000000001` (설명용 예시, 인덱스는 0부터 시작)
  - 기존 사람은 0번과 9번 자리에 앉아 있다.
  - 1번과 8번 자리에 추가하면 사람들의 위치는 `[0, 1, 8, 9]`이고 최소 거리는 1이다.
  - 3번과 6번 자리에 추가하면 위치는 `[0, 3, 6, 9]`이고 최소 거리는 3이다.
  - 양 끝 사이의 거리 9를 세 구간으로 나누므로, 세 구간의 길이를 모두 3보다 크게 만들 수는 없다. 따라서 정답은 **3**이다.

- 구현에서 주의할 점
  - 새로 앉힌 두 사람 사이의 거리만 최대화하면 안 된다. 기존 사람과 가까워지는 경우도 함께 고려해야 한다.
  - `mn`은 배치마다 초기화하고, 전체 정답을 저장하는 `mx`는 반복문 밖에서 한 번만 초기화한다.
  - 후보 선택에서는 `(i, j)`와 `(j, i)`를 모두 검사하지만, 거리 계산에서는 `k < l`인 쌍만 검사한다.
  - `mn = 100`은 최소 거리의 초기 상한이다. 일반화할 때는 가능한 최대 거리 `n - 1`보다 큰 `n`이나 `float('inf')`를 쓰면 입력 크기에 의존하는 상수를 없앨 수 있다.

- 시간복잡도, 공간복잡도 관점에서의 성능 비교
  - 시간복잡도: **O(n⁴)**
    - 두 자리를 고르는 바깥쪽 반복문이 최대 O(n²), 각 배치에서 모든 좌석 쌍의 거리를 검사하는 안쪽 반복문이 O(n²)이다.
    - 빈자리 수를 E라고 하면 거리 계산은 E(E - 1)개의 후보에 대해 수행되며, 최악의 경우 전체 시간은 O(n⁴)이다.
  - 공간복잡도: **O(n)**
    - 좌석 상태 리스트를 저장하는 데 O(n)이 필요하다.
    - 같은 리스트에 임시 배치한 뒤 복구하므로, 좌석 저장 공간 외의 추가 공간은 O(1)이다.
  - 개선 방법과 비교
    - `j`를 `i + 1`부터 순회하면 같은 두 자리를 반대 순서로 선택하는 중복을 없앨 수 있다. 다만 전체 시간복잡도는 여전히 O(n⁴)이다.
    - 일렬로 정렬된 사람들의 최소 거리는 인접한 두 사람 사이에서 나온다. 좌석을 한 번 순회하며 직전에 사람이 있던 위치와의 차이만 비교하면, 배치 하나의 최소 거리를 O(n)에 구할 수 있다.
    - 두 자리 선택은 유지하고 거리 계산만 한 번의 순회로 바꾸면 전체 시간복잡도를 **O(n³)**으로 줄일 수 있다. 공간복잡도는 O(n)으로 동일하다.

### 회고

- 몇 번만에 성공했는지: 1번
- 잘한 점:
  - 두 자리를 선택하는 단계와 배치의 최소 거리를 계산하는 단계를 분리해 완전탐색으로 구현했다.
  - `min`으로 각 배치를 평가하고 `max`로 최종 정답을 갱신해 문제의 조건을 그대로 코드에 반영했다.
  - 임시 배치 후 원상 복구해 각 후보를 같은 초기 상태에서 비교했다.
  - 기존 사람을 포함한 모든 사람 쌍의 거리를 확인해 놓치는 조건 없이 배치를 평가했다.
- 개선할 점 (AI):
  - `j`의 범위를 `range(i + 1, n)`으로 바꾸면 중복 배치를 줄이고 `i == j` 검사도 없앨 수 있다.
  - 모든 사람 쌍을 검사하는 대신 왼쪽부터 순회하며 인접한 사람 사이의 거리만 확인하면 O(n³)으로 개선할 수 있다.
  - `mx`, `mn`, `ln`을 각각 `best_distance`, `min_distance`, `distance`처럼 바꾸면 변수의 역할이 더 분명해진다.
  - `mn = 100` 대신 `mn = n` 또는 `float('inf')`를 사용하면 최소 거리 초기화의 의도가 드러난다.
