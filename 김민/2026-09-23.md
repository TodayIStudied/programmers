### 접근 방식 : 문자열 탐색 및 진법 변환

- 문자열에서 '0'을 직접 제거하는 대신, `count_one` 함수로 '1'의 개수만 세어 지워진 '0'의 개수를 빠르게 계산했습니다.
- 길이를 2진수로 바꾸는 과정은 `to_binary` 함수로 분리하여 모듈화했습니다.

### 회고

- 몇 번만에 성공했는지 : 1번
- 잘한 점 : 불필요한 문자열 생성을 피해 성능을 높였고, 핵심 로직을 함수로 분리하여 코드 가독성을 챙겼습니다.
- 개선할 점 : 직접 만든 `count_one` 함수 대신 C++ STL의 `std::count(s.begin(), s.end(), '1')`을 활용하면 코드를 훨씬 짧고 간결하게 짤 수 있습니다. 앞으로는 내장 함수를 적극 활용해야겠습니다.
