### 접근 방식 : 문자열 탐색 / 정렬
- 전화번호 목록을 문자열 기준으로 정렬한다.
- 문자열을 정렬하면 같은 문자로 시작하는 전화번호들이 서로 인접하게 배치된다.
- 모든 전화번호를 서로 비교하지 않고 현재 번호와 바로 다음 번호만 `startswith()`로 비교한다.

### 회고
- 몇 번만에 성공했는지 : GPT 도움으로 문법 학습 후 1회
- 잘한 점 :
  - 처음에는 SQL의 `LIKE 'a%'`처럼 문자열의 시작을 확인하는 Python 문법이 있을 것이라고 생각했고, `startswith()`를 찾았다.
  - `startswith()`를 사용하더라도 모든 전화번호를 이중 반복문으로 비교하면 시간복잡도가 커질 수 있다고 생각했다.
  - 처음에는 글자 수가 짧은 순서로 정렬하려고 했지만, 일반 `sort()`를 해보니 접두어 관계의 문자열들이 인접하게 배치되는 것을 확인했다.
  - 여기서 버블 정렬처럼 앞뒤 값만 비교하면 되겠다고 생각해 반복 비교를 줄였다.

- 새로 배운 점 :
  - Python에서는 문자열이 특정 문자열로 시작하는지 `startswith()`로 확인할 수 있다.

```python
"1195524421".startswith("119")
# True
```

- 느낀 점 :
  - `set`을 이용하면 존재 여부를 빠르게 확인할 수 있고, 정렬을 이용하면 아예 비교해야 할 번호들을 서로 붙일 수도 있다는 것을 알게 되었다.
  - 특히 이미 자주 사용했던 `sort()`를 **비교할 대상을 인접하게 만드는 용도**로도 사용이 가능해, 이 점도 기억해야 할 부분이라 느꼈다.
