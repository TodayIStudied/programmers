# 폰켓몬

## 문제 정보

* 플랫폼: Programmers
* 난이도: Level 1
* 문제 번호: 1845
* 사용 언어: Java
* 분류: 해시, 자료구조

## 문제 요약

총 `N`마리의 폰켓몬 중에서 `N / 2`마리를 선택할 수 있다.

같은 번호를 가진 폰켓몬은 같은 종류이며, 선택할 수 있는 폰켓몬 종류의 최대 개수를 구하는 문제이다.

## 문제 접근

처음에는 폰켓몬을 `N / 2`마리 선택한다는 조건에 집중했다.

하지만 이 문제에서 중요한 것은 선택한 폰켓몬의 마릿수가 아니라, 중복되지 않는 폰켓몬의 종류 수를 최대화하는 것이다.

따라서 다음 두 값을 구해야 한다.

1. 선택할 수 있는 폰켓몬 수: `nums.length / 2`
2. 전체 폰켓몬의 종류 수

폰켓몬 번호의 중복을 제거하기 위해 `HashSet`을 사용했다.

`HashSet`에 모든 폰켓몬 번호를 넣으면 중복된 번호는 저장되지 않으므로, `set.size()`를 통해 전체 종류 수를 구할 수 있다.

최종적으로 선택할 수 있는 폰켓몬 수와 전체 종류 수 중 더 작은 값을 반환한다.

## 풀이 코드

```java
import java.util.HashSet;

class Solution {
    public int solution(int[] nums) {
        HashSet<Integer> set = new HashSet<>();

        for (int num : nums) {
            set.add(num);
        }

        int pick = nums.length / 2;
        int kind = set.size();

        return Math.min(pick, kind);
    }
}
```

## 코드 설명

```java
HashSet<Integer> set = new HashSet<>();
```

중복을 허용하지 않는 `HashSet`을 생성한다.

```java
for (int num : nums) {
    set.add(num);
}
```

`nums` 배열에 있는 폰켓몬 번호를 하나씩 `HashSet`에 추가한다.

같은 번호가 여러 번 등장해도 한 번만 저장된다.

```java
int pick = nums.length / 2;
```

문제에서 선택할 수 있는 폰켓몬의 수를 구한다.

```java
int kind = set.size();
```

중복이 제거된 폰켓몬 종류의 수를 구한다.

```java
return Math.min(pick, kind);
```

선택 가능한 폰켓몬 수와 전체 종류 수 중 더 작은 값을 반환한다.

## 예시

입력:

```text
nums = [3, 1, 2, 3]
```

전체 폰켓몬 수는 4마리이므로 2마리를 선택할 수 있다.

중복을 제거한 종류는 다음과 같다.

```text
{1, 2, 3}
```

총 3종류가 있지만 2마리만 선택할 수 있으므로 정답은 2이다.

## 시간 복잡도

`nums` 배열을 한 번 순회하므로 시간 복잡도는 다음과 같다.

```text
O(N)
```

`HashSet.add()`의 평균 시간 복잡도는 `O(1)`이다.

## 공간 복잡도

최악의 경우 모든 폰켓몬 번호가 서로 다르면 `HashSet`에 `N`개의 값이 저장된다.

```text
O(N)
```

## 새롭게 배운 내용

### HashSet

중복된 값을 저장하지 않는 자료구조이다.

생성 방법:

```java
HashSet<Integer> set = new HashSet<>();
```

값 추가:

```java
set.add(value);
```

저장된 값의 개수 확인:

```java
set.size();
```

특정 값이 있는지 확인:

```java
set.contains(value);
```

### Math.min

두 값 중 더 작은 값을 반환한다.

```java
Math.min(a, b);
```

## 배운 점

처음에는 중복되지 않는 값을 어떻게 구해야 할지 감이 오지 않았다.

하지만 문제에서 요구하는 것이 폰켓몬의 전체 마릿수가 아니라 종류의 수라는 것을 확인했고, 중복을 제거할 수 있는 `HashSet`을 사용하면 된다는 것을 배웠다.

앞으로 문제에서 중복 제거, 서로 다른 값의 개수, 고유한 값이라는 표현이 나오면 `Set` 자료구조를 먼저 떠올려봐야겠다.
