# K번째수

## 문제 정보

- 플랫폼: Programmers
- 난이도: Level 1
- 문제 번호: 42748
- 사용 언어: Java
- 분류: 정렬

---

## 풀이 코드

```java
import java.util.*;

class Solution {
    public int[] solution(int[] array, int[][] commands) {

        int[] answer = new int[commands.length];

        for (int i = 0; i < commands.length; i++) {

            int start = commands[i][0];
            int end = commands[i][1];
            int k = commands[i][2];

            int[] sliced = Arrays.copyOfRange(
                array,
                start - 1,
                end
            );

            Arrays.sort(sliced);

            answer[i] = sliced[k - 1];
        }

        return answer;
    }
}
```

# 오늘 배운 것

## 1. Arrays.sort() — 배열 정렬

Java에서 배열을 정렬할 때 `Arrays.sort()`를 사용할 수 있다.

```java
int[] numbers = {5, 2, 6, 3};

Arrays.sort(numbers);
```

결과:

```text
[2, 3, 5, 6]
```

기본적으로 오름차순으로 정렬된다.

### 중요한 점

`Arrays.sort()`는 정렬된 새로운 배열을 반환하는 것이 아니라 **기존 배열 자체를 변경한다.**

따라서 다음과 같이 사용할 수 없다.

```java
int[] sorted = Arrays.sort(numbers); // X
```

다음처럼 사용한다.

```java
Arrays.sort(numbers); // O
```

즉,

```text
Before

numbers = [5, 2, 6, 3]

        ↓ Arrays.sort(numbers)

After

numbers = [2, 3, 5, 6]
```

원본 데이터 자체가 변경된다.

---

## 2. Arrays.copyOfRange() — 배열의 일부 복사

배열의 특정 범위만 가져와 새로운 배열을 만들고 싶을 때 사용할 수 있다.

```java
Arrays.copyOfRange(array, start, end);
```

예를 들어

```java
int[] array = {1, 5, 2, 6, 3, 7, 4};

int[] sliced = Arrays.copyOfRange(array, 1, 5);
```

결과:

```text
sliced = [5, 2, 6, 3]
```

원본 배열은 그대로 유지된다.

```text
array  = [1, 5, 2, 6, 3, 7, 4]
sliced = [5, 2, 6, 3]
```

### 범위 지정에서 주의할 점

`copyOfRange()`는

```text
시작 index → 포함
끝 index   → 포함하지 않음
```

방식이다.

따라서

```java
Arrays.copyOfRange(array, 1, 5);
```

는

```text
index 1
index 2
index 3
index 4
```

까지만 복사한다.

`index 5`는 포함하지 않는다.

---

## 3. 왜 copyOfRange()를 사용하는가?

처음에는

> 왜 굳이 copyOfRange로 복사하지?
> 원본 데이터를 건드리지 않기 위해서인가?

라는 의문이 들었다.

이번 문제에서는 원본 배열을 여러 명령에서 반복해서 사용한다.

만약 원본 배열 자체를 정렬하거나 변경해버리면 다음 명령을 처리할 때 처음 입력받은 배열과 달라질 수 있다.

그래서

```text
원본 array
     ↓
필요한 범위만 복사
     ↓
sliced
     ↓
복사본 정렬
```

방식으로 처리한다.

```java
int[] sliced = Arrays.copyOfRange(array, start - 1, end);

Arrays.sort(sliced);
```

이렇게 하면

```text
array  → 그대로 유지
sliced → 정렬됨
```

이 된다.

### 여기서 배운 중요한 개념

메서드를 사용할 때 단순히 사용법만 보는 것이 아니라

```text
이 메서드는 원본을 변경하는가?

또는

새로운 데이터를 만들어 반환하는가?
```

를 확인하는 것이 중요하다.

이번에 사용한 두 메서드를 비교하면:

```text
Arrays.sort()
→ 기존 배열 자체를 변경

Arrays.copyOfRange()
→ 새로운 배열을 만들어 반환
```

이다.

실제 코드를 작성할 때도 원본 데이터를 유지해야 하는 상황인지, 직접 변경해도 되는 상황인지 생각해야 한다.

---

## 4. copyOfRange()의 end에는 왜 -1을 하지 않는가?

처음 보면 시작 위치에는

```java
start - 1
```

을 사용하는데 끝 위치에는

```java
end
```

를 그대로 사용하는 것이 헷갈릴 수 있다.

예를 들어 문제에서

```text
2번째 ~ 5번째
```

를 가져오라고 한다면 실제 index는

```text
index 1 ~ index 4
```

이다.

따라서 얼핏 보면

```text
start - 1 = 1
end - 1   = 4
```

를 넣어야 할 것 같다.

하지만 `copyOfRange()`의 마지막 값은 **포함하지 않는다.**

그래서

```java
Arrays.copyOfRange(array, 1, 5);
```

라고 해야 실제로

```text
index 1, 2, 3, 4
```

가 복사된다.

따라서 이번 문제에서는

```java
Arrays.copyOfRange(array, start - 1, end);
```

가 된다.

# 오늘의 핵심 정리

오늘 처음으로 **정렬**을 사용했다.

`Arrays.sort()`를 이용하면 배열을 오름차순으로 정렬할 수 있으며, 이 메서드는 새로운 배열을 만드는 것이 아니라 **기존 배열 자체를 변경한다.**

반대로 `Arrays.copyOfRange()`는 원본 배열의 특정 범위를 **새로운 배열로 복사해서 반환한다.**

따라서 이번 문제에서는

```text
원본 배열
   ↓
필요한 범위 복사
   ↓
복사본 정렬
   ↓
k번째 값 확인
```

순서로 처리했다.

특히 앞으로 Java 메서드를 사용할 때

```text
원본 데이터를 직접 변경하는가?
새로운 데이터를 반환하는가?
```

를 구분해서 보는 것이 중요하다는 것을 배웠다.
