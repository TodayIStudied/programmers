### 접근 방식 : 1. 그리디 
- 왜 이 방식으로 풀었나?
  - N이 1e9라서 BFS, BFS 0-1, 백트래킹 등 적용해봐도 제한 시간 내에 풀이 불가능함.
  - 무조건 답이 존재하는 문제이기 때문에 그리디가 가능하다.
  - 1에서 시작하면 재귀로 빠지지만 역방향으로 내려오면 답은 하나
  - 아이디어 떠올리기 어려웠음. 
    ```
    def solution(n):    
      answer = 0
      while(n>0):
          if(n%2==0):
              n//=2
          else:
              n-=1
              answer +=1
      return answer
    ```
- 시간복잡도, 공간복잡도 관점에서의 성능 비교
  - 메모리: 11 MB, 시간: 0.01 ms
