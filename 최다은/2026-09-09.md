### 접근 방식 : 1. 백트래킹 + 방문 처리 2차원 배열 
- 왜 이 방식으로 풀었나?
  - 그냥 백트래킹 우선 떠올랐고
  - N이 12라서 방문 처리 2차원으로 해도 터질 것 같지 않았음.
  - 서로 공격할 수 없도록 배치 == 이동했을 때 영원히 만나지 않는다. 
  - 행과 열은 모두 달라야 한다. 
  - 백트래킹으로 배치 완료가 N인 경우 답을 업데이트하기
  - visited 배열 만든다. N이 작아서 가능 
  1. 현재 노드에서 방문 가능한 것들 방문 처리한다. (0일 경우 예외 처리)
  2. 자기 자신의 다음 col 중 방문 가능한 것 하나 선택해서 방문하고 cnt 업데이트 
  3. 반복한다. 
  4. 만약 cnt==N인 경우 종료하고 answer +=1 

- 시간복잡도, 공간복잡도 관점에서의 성능 비교
  - 메모리: 11.6 MB, 시간: 6185.06 ms
  - N이 최대 12인데 2d 144짜리를 check했다가 uncheck했다가를 모든 분기에 대해 처리해서 시간 복잡도 높음
