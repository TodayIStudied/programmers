### 접근 방식 : [a, b] 이면 꺼낼 수 있다
line이 [[a,b], [c,d]] 처럼 생긴 배열 리스트일 때,
나의 경우
```
for i in lines:
    for j in range(i[0], i[1]):
```
를 사용했지만,

```
for start, end in lines:
```
를 통해서 한 번에 꺼낼 수 있음을 알게 되었다.

### 접근 방식 : lambda x 정렬 
- 절댓값정렬해두고, 인덱스 묶으려고 했음
근데 lambda 값을 사용하면 쉽게 가능하다는 것을 배웠음.

```
sorted(어떤걸, key=lambda x: (abs(n-x), -x))
```
- 여기서 -x는 내림차순
- abs는 절댓값
