### 접근 방식 : 문자열 치환 + 시뮬레이션
- `C#`, `D#`, `F#`, `G#`, `A#`, `B#`을 소문자 한 글자로 치환해 음 하나 = 문자 하나로 통일
- 시작·종료 시각을 분 단위로 바꿔 재생 시간 계산
- 악보를 재생 시간만큼 반복해서 실제로 재생된 멜로디 생성
- `find()`로 기억한 멜로디 `m`이 포함되는지 확인
- 여러 곡이 맞으면 재생 시간이 가장 긴 곡, 같으면 먼저 입력된 곡 선택 / 없으면 `"(None)"`

### 회고
- 몇 번만에 성공했는지 : 1번
- 잘한 점 : `#` 붙은 음을 한 글자로 치환해서 부분 문자열 비교 문제로 단순화함
- 개선할 점 :
  - C++의 `string::replace()`는 `(위치, 길이, 문자열)` 형태라 Java처럼 문자열로 찾아 바꿀 수 없음. `find()`와 반복문을 같이 써야 함
  - 치환 문자를 `H`처럼 임의로 정하면 원래 음과 겹칠 수 있음. 소문자처럼 겹치지 않는 문자를 써야 함
  - 테스트케이스 업데이트로 `B#`도 등장함. 문제에 없는 입력도 빠짐없이 처리해야 함
