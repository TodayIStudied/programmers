- 알고리즘 : DFS / 그래프 / 완전탐색

### 접근 방식 : 완전탐색 + DFS
- 송전탑을 노드, 전선을 간선으로 표현하고 인접 리스트를 생성한다.
- DFS에서 끊은 전선을 제외하고 연결된 송전탑의 개수를 계산한다.
- 두 전력망의 송전탑 개수 차이를 계산하고 최솟값을 갱신한다.

- 공간복잡도 : `O(N)` — 인접 리스트, 방문 배열, 재귀 호출 스택

### 회고
- 몇 번만에 성공했는지 : 4회 시도 후 GPT의 도움을 받아 해결

- 잘한 점 :
  - 전선을 하나씩 끊어보며 송전탑의 개수를 세는 DFS 접근 방식을 구현했다
  - 인접 리스트와 DFS를 활용했다.

- 개선할 점 :
  - 인접 리스트와 DFS의 사용 목적은 이해했지만, 이를 실제 코드로 구현하는 과정을 성공하지 못 했다.
  - 특히 DFS 함수에 어떤 매개변수를 전달하고, 재귀 호출 방식을 구현하지 못 했다.

- 새로 배운 점 :
  - 인접 리스트는 각 노드와 연결된 노드들을 저장하는 자료구조이며, `graph[node]`로 인접 노드에 접근할 수 있다.
  - 양방향 그래프에서는 `graph[a].append(b)`와 `graph[b].append(a)`를 모두 작성해야 한다.
  - `count += dfs(next_node, ...)`처럼 재귀 함수의 반환값을 누적하여 연결된 노드의 개수를 계산할 수 있다.
  - 전선을 실제로 삭제하지 않고 DFS에서 해당 간선만 건너뛰는 방식으로도 문제를 해결할 수 있다.
  - 이번 문제는 백트래킹이 아니라 DFS와 완전탐색을 활용하므로, 각 DFS에서 방문 상태를 복구할 필요가 없다.

- 느낀 점 :
  - 알고리즘의 개념을 이해하는 것과 이를 직접 함수로 구현하는 것은 별개의 능력이라는 점을 느꼈다.
  - 알고리즘을 이해했다면, 직접 함수를 설계하고 작성하는 연습이 필요하다.
