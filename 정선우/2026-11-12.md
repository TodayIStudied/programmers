# 프로그래머스 Lv.2 — 후보키

### 문제 설명
- 풀이 URL : [후보키](https://github.com/sunoo2468/codingTestPre/blob/main/Python/%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%98%EB%A8%B8%EC%8A%A4/2/42890.%E2%80%85%ED%9B%84%EB%B3%B4%ED%82%A4/%ED%9B%84%EB%B3%B4%ED%82%A4.py)
- 난이도 : Lv.2
- 알고리즘 : 완전탐색, 조합, 집합
- 학습 목표 : 조합 생성(유일성, 최소성)

### 접근 방식 : 조합 완전탐색 + 집합

1. 커비네이션으로 중복 없이 조합을 만든다.
2. 기존 후보키가 현재 조합의 부분집합이라면 최소성을 만족하지 않으므로 건너뛴다
3. 모든 행의 튜플을 `set`에 저장해 중복을 제거한다.
4. 최소성과 유일성을 모두 만족하는 조합을 `candidate_keys`에 저장한다.

- 시간복잡도 : 최악의 경우 `O(2^C × (R × C + C²))` — 컬럼 조합을 검사하며 유일성과 최소성을 확인한다. (`R`: 행 수, `C`: 컬럼 수)
- 공간복잡도 : `O(R × C + 2^C × C)` — 유일성 검사에 사용하는 집합과 후보키 저장 공간


### 회고

- **몇 번 만에 성공했는지** : 2회

- **잘한 점**
  - 후보키의 유일성과 최소성을 각각 검증하도록 로직을 구성한 방식을 학습했다.
  - 집합으로 중복을 제거하고 부분집합 검사로 불필요한 조합을 제외하는 방법을 이해했다.

- **개선할 점**
  - `combinations()`를 사용하지 않고 DFS와 백트래킹으로 컬럼 조합을 직접 생성하는 연습이 필요하다.
  - `issubset()`을 이용한 최소성 검사 과정을 직접 예제로 확인해야 한다.
  - 조합의 수가 증가할 때 시간복잡도가 어떻게 변하는지 이해할 필요가 있다.

- **새로 배운 점**
  - 후보키는 유일성과 최소성을 모두 만족해야 한다.
  - `issubset()`은 한 집합이 다른 집합의 부분집합인지 확인하는 메서드다.

- **느낀 점**
  - 이전 문제에서는 DFS를 이용해 연결된 영역이나 사이클을 탐색했다면, 이번에는 가능한 컬럼 조합을 생성하고 조건을 검증하는 완전탐색 문제를 학습했다.
  - 이미 확인한 결과를 활용해 불필요한 탐색을 줄이는 과정이 중요하다는 점을 알게 되었다.
  - 특히 데이터베이스에서 배운 후보키 개념을 알고리즘 문제에 적용하면서, 이론적인 개념이 실제 코드로 어떻게 구현되는지 이해할 수 있었다.
  - 앞으로는 조합을 직접 생성하는 DFS와 백트래킹도 구현해 보고 싶다.
