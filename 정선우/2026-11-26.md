# 프로그래머스 Lv.2 — 가장 큰 정사각형 찾기

### 문제 설명
- 풀이 URL : [가장 큰 정사각형 찾기](https://github.com/sunoo2468/codingTestPre/blob/main/Python/%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%98%EB%A8%B8%EC%8A%A4/2/12905.%E2%80%85%EA%B0%80%EC%9E%A5%E2%80%85%ED%81%B0%E2%80%85%EC%A0%95%EC%82%AC%EA%B0%81%ED%98%95%E2%80%85%EC%B0%BE%EA%B8%B0/%EA%B0%80%EC%9E%A5%E2%80%85%ED%81%B0%E2%80%85%EC%A0%95%EC%82%AC%EA%B0%81%ED%98%95%E2%80%85%EC%B0%BE%EA%B8%B0.py)
- 난이도 : Lv.2
- 알고리즘 : 동적 계획법(DP)
- 학습 목표 : 2차원 배열에서 DP 상태 정의 및 점화식 설계

### 접근 방식 : DP

1. 배열의 각 칸을 정사각형의 오른쪽 아래 꼭짓점으로 생각한다.
2. 현재 칸이 0이면 정사각형을 구성할 수 없으므로 건너뛴다.
3. 현재 칸이 1이면 위쪽, 왼쪽, 왼쪽 위 대각선의 값 중 최솟값에 1을 더한다.
4. 배열을 순회하면서 정사각형의 최대 변의 길이를 갱신한다.
5. 최대 변의 길이를 제곱하여 넓이를 반환한다.

- 시간복잡도 : `O(N × M)`
- 공간복잡도 : `O(1)` — 기존 배열을 DP 배열로 재사용하며 원본 배열이 변경된다.

### 회고

- **몇 번 만에 성공했는지** : 2회
- **잘한 점** : 이전 계산 결과를 재사용하여 반복적인 영역 탐색을 줄이고, 별도의 DP 배열 없이 공간복잡도를 최적화하는 방법을 학습했다.
- **개선할 점** : DP 문제에서 각 상태가 의미하는 값을 정의하고 점화식을 도출하는 연습이 필요하다.
- **새로 배운 점** : 2차원 DP에서는 위쪽, 왼쪽, 대각선 등 여러 인접 상태를 활용할 수 있으며, 최솟값을 이용해 확장 가능한 정사각형의 크기를 결정할 수 있다.
- **느낀 점** : 모든 정사각형의 크기를 직접 확인하지 않고 주변 칸의 정보만으로 최대 크기를 구할 수 있다는 점에서 생각의 전환점이 되었던 것 같다.. DP에서는 반복문을 구현하는 것보다 상태의 의미와 점화식을 설계하는 과정이 중요하다는 점을 배웠다.
