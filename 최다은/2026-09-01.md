### 접근 방식 : 1. 백트래킹
- 왜 이 방식으로 풀었나?
  - 라이언이 어피치를 이기는 모든 경우를 탐색해야 문제 조건에 부함하는 답을 반환할 수 있음
  - 그렇기에 모든 경우를 탐색하기는 해야 하는데 대상을 최대한 줄여야 함.
  - 어차피 경기 규칙을 고려해보면 라이언은 하나의 점수에 대해 0발 쏘거나 (어피치+1)발 쏘거나 둘 중 하나임
  - 즉, 2^(점수 개수) 경우만 고려하면 되는데 점수 개수는 11로 고정되어 2048로 시간복잡도 문제 안됨.
  - 그러면 일종의 트리 형태로 점수가 0인 상태에서 뻗어나가며 조건을 만족하지 않으면 중단하고 만족하면 값을 비교하는 문제임 == 백트래킹
- 까다로운 조건 :
  - 라이언도 총 n발을 쏘아야 한다.
    - 그런데 백트래킹을 돌리다 보면 n발을 충족하지 못한 채 종료될 수도 있음.
    - 이 경우도 점수를 카운트 해야 하고 남은 점수도 분배해야 함.
    - 남은 점수를 어떻게 분배해야 하냐? 가장 낮은 점수를 더 많이 맞힌 경우를 찾을 수 있도록 : 0점 과녁에 몰아주기
  - 만약 점수 차이가 동일하면 낮은 점수를 더 많이 맞힌 경우를 선택해야 한다. 
    - 낮은 점수는 어디에? 리스트 맨 뒤에
    - 그렇다면 리스트를 거꾸로 정렬시켰을 때 더 우선순위가 높은 것을 선택해야 함. 

- 시간복잡도, 공간복잡도 관점에서의 성능 비교
  - 메모리: 11.8 MB, 시간: 1.41 ms
