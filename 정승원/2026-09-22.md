### 문제 설명
- 문제명: 요일 맞추기
- 풀이 URL: [요일 맞추기 — 내 풀이 코드](https://github.com/HappyPotatohappy/CodingTest/blob/main/trail2/요일%20맞추기/guess-day-of-week.py)
- 사용 언어: Python
- 2011년 `m1`월 `d1`일이 월요일일 때, 같은 해 `m2`월 `d2`일이 무슨 요일인지 구한다.
- 2011년은 윤년이 아니므로 2월은 28일까지다. 두 날짜는 모두 2011년에 실제로 존재하는 날짜만 주어진다.
- 두 번째 날짜가 첫 번째 날짜보다 앞설 수도 있다. 예제 `5 4 5 3`의 답은 `Sun`이다(5월 4일이 월요일이면 하루 전인 5월 3일은 일요일).
- 출력은 `Sun, Mon, Tue, Wed, Thu, Fri, Sat` 형태다.
- 제약: `1 ≤ m1, m2 ≤ 12`, `1 ≤ d1, d2 ≤ 31`, 시간 제한 1초.

### 접근 방식 : 1. 두 날짜 사이의 일수 차이를 구한 뒤 7로 나눈 나머지로 요일 결정
- 왜 이 방식으로 풀었나?
  - 요일은 7일마다 반복되므로, 기준 날짜(월요일)로부터 며칠 떨어져 있는지만 알면 `(차이 % 7)`로 요일이 바로 정해진다.
  - 각 달의 일수를 `mon = [0, 31, 28, 31, ...]`에 담아 두고, 인덱스를 월과 맞추기 위해 0번째에 0을 넣었다.
  - `day = ["Mon", "Tue", ..., "Sun"]`처럼 월요일을 0번에 두어, 기준 날짜(차이 0)가 자연스럽게 `Mon`이 되도록 했다.

- 일수 차이를 구하는 방법 -> 이것이 핵심.
  - `m1 <= m2`인 경우: `m1`월부터 `m2 - 1`월까지의 일수를 전부 더한 뒤 `d2 - d1`을 더한다. 예를 들어 3월 10일 → 5월 4일이면 `mon[3] + mon[4] + (4 - 10) = 55`일이다.
  - `m1 > m2`인 경우: 반대로 `m2`월부터 `m1 - 1`월까지의 일수를 빼고 `d2 - d1`을 더한다. 결과가 음수가 되며, 이는 "기준일보다 며칠 앞선 날짜"라는 의미다.
  - 같은 달이면 `for` 루프가 한 번도 돌지 않고 `d2 - d1`만 남으므로 별도 분기가 필요 없다.
  - 음수 차이를 따로 보정하지 않아도 되는 이유는 파이썬의 `%` 연산이 항상 0 이상의 나머지를 돌려주기 때문이다. `-1 % 7 == 6`이므로 하루 전은 `day[6] = "Sun"`이 된다.

- 생각해볼 수 있는 다른 방법 -> 코드가 더 단순해서 이쪽이 낫다.
  - 두 날짜 각각을 "1월 1일부터 며칠째인지"(day of year)로 바꾼 뒤 그 차이를 구한다. `doy(m, d) = sum(mon[1:m]) + d`로 한 줄에 계산되고, 차이 `doy(m2, d2) - doy(m1, d1)`이 자동으로 부호를 가지므로 `m1 > m2` 분기가 사라진다.
  - `datetime.date(2011, m2, d2) - datetime.date(2011, m1, d1)`으로 일수 차이를 얻는 방법도 있다. 다만 시뮬레이션 트레일의 의도(날짜 계산을 직접 구현)와는 맞지 않아 사용하지 않았다.

- 시간복잡도, 공간복잡도 관점에서의 성능 비교
  - 시간복잡도: **O(1)**
    - 월 단위 루프가 최대 11번 돌고, 나머지는 상수 연산이다. 입력 크기와 무관하게 실행 시간이 일정하다.
  - 공간복잡도: **O(1)**
    - 월별 일수 배열 13칸, 요일 문자열 배열 7칸, 정수 변수 몇 개만 사용한다.

### 회고
- 몇 번만에 성공했는지: 1번
- 잘한 점:
  - 요일 문제를 "달력을 시뮬레이션"하지 않고 "일수 차이 % 7"로 환원해서 풀었다.
  - 두 번째 날짜가 앞설 수 있다는 점을 놓치지 않고 `m1 > m2` 분기를 두었고, 음수 나머지를 파이썬 `%`가 알아서 처리한다는 점을 이용했다.
  - 요일 배열의 시작을 `Mon`으로 맞춰서 기준 요일 보정 계산을 없앴다.
- 개선할 점:
  (AI)
  - 코드 마지막 주석("1월 1일부터 며칠이 지났는지 카운트하면")대로, 각 날짜를 1월 1일 기준 누적 일수로 바꿔 빼면 `if/else` 두 갈래가 하나로 합쳐진다.
    ```python
    def doy(m, d):
        return sum(mon[1:m]) + d
    print(day[(doy(m2, d2) - doy(m1, d1)) % 7])
    ```
  - `mday += d2 - d1`이 `if`와 `else` 양쪽에 중복으로 들어 있다. 분기 밖으로 빼면 한 줄로 줄어든다.
  - `mday`라는 이름은 "달 일수"처럼 읽힌다. `diff`나 `days_between`처럼 의미가 드러나는 이름이 낫다.
